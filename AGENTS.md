# Инструкция ИИ-агентам: LunexEconom как библиотека исходников

Этот репозиторий содержит **исходники LunexEconom V2**, которые можно изучать для создания **новой отдельной игры**. Не считай новый проект продолжением V2 и не переносите его продуктовые решения автоматически.

## С чего начать

1. `docs/source_manifest.json` — машиночитаемый индекс: идентификаторы, пути, тесты, статус интеграции.
2. `docs/SOURCE_LIBRARY.md` — правила повторного использования.
3. `docs/SOURCE_AUDIT.md` — результаты проверок и ограничения.
4. `docs/MODULE_INDEX.md` — карта исходников.
5. `docs/REUSE_CATALOG.md` — приоритетные механики и рекомендации.
6. `docs/AI_RULES.md` — обязательные правила работы в **этом** репозитории.

## Как извлекать механику

- Ищи компонент по `id` или `name_ru` в манифесте.
- Читай исходники, тесты и импорты. Проверяй зависимости и схемы данных.
- Отделяй автономные модели `tools/sim/` от подключённого сервера `server/`.
- Сохраняй целочисленную арифметику денег, инварианты учёта и детерминированные тесты.
- Переноси только минимально необходимые файлы **в отдельный репозиторий** с адаптацией контрактов.
- Не переносить боевые конфигурации, токены, ключи, персональные данные, URL, БД, APK, брендинг и настройки VPS.
- `docs/gdd/` является историей проектирования V2, а не техническим заданием новой игры.
- Не заявляй, что модуль полностью работает, только по наличию файла или теста.

## Минимальная проверка

Для документационных изменений достаточно зелёной GitHub CI. Скриншоты и визуальные регрессионные тесты не требуются. Для переноса конкретного модуля используй его целевые тесты в новом проекте.

## Ограничения

Без прямого разрешения владельца не менять продакшен, VPS, базы, ключи и релизы. Работать через отдельную ветку и PR. Слияние только после зелёной CI. При противоречии следуй `docs/AI_RULES.md`.
