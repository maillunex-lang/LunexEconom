# Лендинг V2

Локально: `python3 -m http.server 8080 --directory web`, затем http://localhost:8080.

Статический сайт, без сторонних трекеров и зависимостей. Иллюстрации созданы CSS; галерея явно обозначена как макеты, а не игровые скриншоты. Пока APK не собран и не опубликован, ссылка загрузки намеренно отключена. Публикация APK потребует настоящей проверенной ссылки, а не фиктивного файла.
