# Лендинг V2: Forest Glass

Открыть локально: `python3 -m http.server 8080 --directory web`.

Статическая, русскоязычная страница со светлой/тёмной темами. APK считывается из `./update.json`; если манифест недоступен, используется страница последнего релиза GitHub. Дорожная карта считывается из `./roadmap.json`, при выключенном JavaScript показана встроенная копия. Никаких cookies и внешних ресурсов.

Полная инструкция, схема данных и ограничения публикации: `docs/web.md`. Публикация на VPS не выполнялась.
