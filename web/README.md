# Лендинг V2: Forest Glass

Открыть локально: `python3 -m http.server 8080 --directory web`.

Статическая, русскоязычная страница со светлой/тёмной темами. Сборка читается из `./latest.json` (отдельный информационный файл, его пишет сервер). Если файла нет или он неверен, используется подписанный `./update.json`, иначе страница последнего релиза GitHub. Канал `test` не выглядит как обычная игра. Дорожная карта считывается из `./roadmap.json`, при выключенном JavaScript показана встроенная копия и ссылка на релизы. Никаких cookies и внешних ресурсов. Пример `web/tests/fixtures/latest.example.json` на сайт не публикуется.

Полная инструкция, схема данных и ограничения публикации: `docs/web.md`. Публикация на VPS не выполнялась.
