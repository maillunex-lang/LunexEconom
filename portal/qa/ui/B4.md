# B4. Интерфейсные интеграции, граф и завершение

## Реализовано
- MAX и Telegram: GET настроек, POST создания кода (10 минут), проверка привязки, отправка теста, отключение с подтверждением, переключатели шести типов событий. Запросы к реальному API A4; секреты и chat ID не показываются.
- Ссылки `#task/ID`: после входа открывают задачу в последнем выбранном проекте (при отсутствии выбора в первом доступном), неизвестный ID сообщает об ошибке. Работают при загрузке и при изменении hash.
- Web Share Target: страница читает `?title=...&text=...` и показывает редактируемый текст, выбор проекта, подтверждение и отмену; автоматического сохранения нет. Серверный manifest менять запрещено.
- Граф зависимостей: прокручиваемая сетка по глубине DAG, зависимости подписаны стрелкой ←, статусы окрашены, выделен один самый длинный путь по числу задач. Если серверный `/graph` недоступен, строится граф из уже загруженного плана.
- Поиск задач и идей: серверный `/search` при наличии, иначе поиск в загруженном проекте по названию, ID, цели и тексту идей. Без результатов и при ошибке выводятся пояснения.
- Настройки проекта: карточки резервных копий, экспорт JSON, импорт JSON, удаление с вводом точного slug и отдельным подтверждением. Все операции направлены только в серверные API, при отсутствии маршрутов не имитируют успех. Глобальный экран резервирования: проверка статуса, создание копии, безопасное сообщение о недоступности скачивания.
- Четыре варианта GitHub: вебхук репозитория, вебхук организации, опрос, вебхук + опрос; инструкция, копирование публичного URL, 5/10/30 минут, запрос `/sync-status`, сохранение `/sync-settings` только при наличии серверной поддержки.
- Экран «Ещё»: уведомления, поиск, граф, идеи, версия и функции. `/api/version` при наличии, без выдумывания версии.
- B6: заголовок «Сегодня» в верхней панели, «← Назад» в задаче, постоянная область деталей рядом с доской на широком экране (от 1200 px), сохранено мобильное представление.

- Headless Chromium: `portal/ui_tests/b4_shots.py` (20 скриншотов Today/Board/Review/Checklist/More), `portal/ui_tests/b4_features.py` (16 скриншотов MAX/Telegram, графа, поиска и копий); 390×844 и 1440×900, обе темы. ## Допущения
1. В `main` нет `docs/gdd/07_*.md`, `09_*.md`, `11_*.md`; прочитаны доступные `03_*.md`, `05_*.md`, `docs/gdd/DECISIONS_APPROVED.md`, `docs/AI_RULES.md`, `docs/portal/05_INTEGRATIONS.md`, `08_DATA_API.md`. Концепт B6 уже слит.
2. В актуальном сервере реализованы A1–A4 частично: уведомления и отчёты есть; `/api/today`, `/api/version`, `/api/backup`, `/api/projects/{slug}/graph`, `/search`, `/export`, `/import`, `/sync-status`, `/sync-settings`, DELETE проекта отсутствуют. UI не создаёт локальных копий и не имитирует успех. Серверный today вызывается только при `window.PORTAL_FEATURE_TODAY===true` (по умолчанию выключен), иначе используется вычисление из реальных задач.
3. В серверном API A4 канал MAX/Telegram требует настроенного бот-токена на сервере; кнопка проверки привязки не гарантирует подключение при отсутствии токена. Никаких токенов в репозитории.
4. «Критический путь» вычислен как наиболее длинная цепь по количеству узлов, поскольку длительности задач в плане нет. На графе зависимости обозначены текстовыми стрелками, а не SVG-линиями.
5. Импорт/экспорт/удаление не включаются на сервере этим PR. Действия показывают безопасную ошибку 404; для полноценной реализации нужен серверный A5.
6. Режим GitHub polling в UI является подготовкой. Пока `/sync-settings` отсутствует, сохранение не происходит. Серверные файлы, миграции и секреты не менялись.
7. Скачивание последней резервной копии оставлено в безопасном неактивном состоянии до утверждения бинарного маршрута. Кнопка сообщает об этом, не скачивая произвольный URL.

## Изменения manifest для директора (серверная зона, НЕ в B4)
В JSON, который отдаёт `GET /manifest.webmanifest`, добавить:
```json
"shortcuts": [
 {"name":"Новая идея","short_name":"Идея","url":"./?action=idea"},
 {"name":"Что делать сейчас","short_name":"Сегодня","url":"./?action=today"}
],
"share_target": {
 "action":"./", "method":"GET", "enctype":"application/x-www-form-urlencoded",
 "params":{"title":"title","text":"text"}
}
```
Сервер должен сохранять префикс `/createportal/` в относительных ссылках. Страница уже обрабатывает `title` и `text` с подтверждением. Обработчик `action=idea` требует доработки после изменения манифеста. Данные из share-target не сохраняются автоматически.
