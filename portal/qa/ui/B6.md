# B6. Редизайн интерфейса CreatePortal v2

## Выполнено
- Четыре вкладки «Сегодня», «Доска», «Проекты», «Ещё». На телефоне фиксированная нижняя панель, на компьютере боковая навигация. Верхняя панель содержит название/назад и аватар, ведущий в меню.
- «Сегодня»: одна основная карточка «Сделайте сейчас» (сданная задача приоритетнее готовой к выдаче), «Идёт сейчас» и три показателя из фактического состояния проектов. При пустом списке предлагается создать проект; при отсутствии ожидающих действий отображается «Всё идёт по плану».
- «Доска»: мобильная лесенка с выделением текущих шагов, переключатель линий A/B/обе и переход к проверке; десктопная дорожная карта сохранена. Из раздела «Доска» без последнего выбранного проекта автоматически открывается первый доступный проект.
- «Проверка работы»: шкала этапов, существующие блоки PR/CI, отчёт и чек-лист, единая контекстная панель «Вернуть / Принять», счётчик незакрытых пунктов и ручная приёмка. Старая дублирующая плавающая панель для сданных задач убрана. Серверная валидация приёмки остаётся обязательной.
- «Ещё»: идеи, настройки, справка, мастер-промпт, протокол, проекты, переключение темы, PWA и выход. Существующие действия создания проекта, планов, аудита, отчёта, возврата и приёмки сохранены.
- Сохранены CSP nonce, безопасный вывод данных через textContent, русские подписи, aria-label/title у кнопок, минимальная высота кнопок и режим reduced-motion.

## Допущения
1. На момент начала B6 утверждённый концепт в PR #119 (`portal-redesign-concept`) ещё не был слит в main; при синхронизации main перед PR он уже был слит. `docs/portal/12_REDESIGN.md` и `docs/portal/mockups/redesign/concept.html` прочитаны напрямую из ветки концепта, но не перенесены и не изменены (зона B6 запрещает `docs/**`). Также прочитаны доступные `docs/portal/07_UI_UX.md`, `11_MOBILE_PWA.md`, `docs/AI_RULES.md`, `docs/gdd/DECISIONS_APPROVED.md`. В `main` отсутствуют `docs/gdd/07_*.md` и `docs/gdd/11_*.md`.
2. Приоритет экрана «Сегодня»: первая сданная задача, затем первая готовая к выдаче; сортировка следует порядку проектов API и пакетов плана. Показатели «У исполнителей», «Ждёт вас», «Принято» считаются из состояний доступных проектов, а не подменяются макетными числами. Ограничение чтения до 12 проектов для защиты мобильного экрана и API.
3. На мобильном оставлена существующая функциональная лесенка B1, с выделением текущего шага и выбором линии. На десктопе оставлены обе исходные формы доски; боковая навигация и ширина карточек обеспечивают разделение навигации и содержимого. Полное двухколоночное представление списка/деталей заменено существующей выдвижной панелью задачи, чтобы не менять поведение B1–B3.
4. API отчётов и метрик зависит от серверной линии A; после слияния A3 адаптирован формат GET отчёта `{report:{body,pr_url}}`, GET чек-листа `{review:{items,revision_count}}`, POST `/review` с `items` и `return/remarks`, а окончательное принятие отправляется отдельным POST `/status` с `manual`. При недоступности серверных маршрутов опасные действия остаются заблокированы. Клиентский редизайн не включает серверные функции и не меняет флаги.
5. Никаких файлов вне `portal/static/**`, `portal/ui_tests/**`, `portal/qa/ui/*.md` не изменялось. Рабочая копия изолирована от продакшена и других задач.
