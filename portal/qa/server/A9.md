# A9. Память для ИИ

## Реализовано
- Ветка portal/a9-memory от origin/main, без изменения portal/memory/**.
- SQLite migration v10: project_decisions, context_links, repo_map_cache; дополнительная проверка существования таблиц при запуске.
- GET context, GET search, GET/POST decisions, POST context-link, GET repo-map, публичный GET /ctx/{token}.
- Контекст ограничен 6000 символами, три роли; поиск BM25 из неизменённого ядра; решения импортируются из docs/gdd/DECISIONS_APPROVED.md при запросе памяти.
- 128-битный случайный токен, в SQLite только SHA-256, срок 24 часа, отзыв, максимум 10 чтений, публичный ответ только текст. В SQLite хранится отфильтрованный снимок контекста.
- Интерфейс «Память»: контекст, роли, предпросмотр, копирование, системное «Поделиться», ссылка с отзывом, поиск с фильтрами, журнал решений, карта репозитория.
- Существующая авторизация сессией и CSRF используется для новых API; публичный маршрут только GET.
- PORTAL_MEMORY=1 по умолчанию, PORTAL_MEMORY=0 отключает маршруты.

## Проверки
- 48 новых тестов в portal/tests/test_a9_integration.py; 40 проверок форм слов, плюс SQLite, роли, ссылки и решения.
- Общий набор существующих тестов до добавления новых: 501 OK.
- Локальный HTTP-тест реального WSGI-сервера: GET контекста без авторизации возвращает 401.
- Снимки 390x844 и 1440x900 в двух темах: НЕ ВЫПОЛНЕНЫ, браузер Chromium/Playwright в текущем окружении не обнаружен. Это блокирует полную приёмку A9.
- Подмена GitHub API: не реализована. Карта репозитория работает через локальный клон с кэшем на час.

## Допущения
1. PORTAL_MEMORY включён по умолчанию в соответствии со специальной спецификацией, несмотря на общее правило отключённых флагов.
2. Для карты репозитория используется только доверенный локальный путь PORTAL_REPO_ROOT; не загружаем произвольные адреса GitHub во избежание SSRF.
3. Публичная ссылка не выдаёт JSON и не раскрывает токен через аудит. Снимок сохраняется только после redact.
4. Существующий GET /search расширен; для совместимости возвращается поле type.
5. Нельзя считать этап полностью принятым до визуальных снимков и полноценного сквозного HTTP-теста авторизованного сценария.
