# A9. Память для ИИ: итоговый отчёт

Ветка portal/a9-memory. PR https://github.com/maillunex-lang/LunexEconom/pull/137. Ядро portal/memory и существующие 22 теста неизменны.

## Реализация
Добавлена миграция v10: project_decisions, context_links, repo_map_cache. Встроены GET context, GET search, GET/POST decisions, GET repo-map, POST context-link, публичный GET /ctx/{token}. Контекст включает план, статусы, события, PR, решения, знания, карту и ограничен 6000 символами. BM25 из исходного ядра ищет с учетом форм слов, по документам, решениям, отчетам, возвратам, знаниям и идеям. Временные ссылки содержат 128-битный CSPRNG токен, в БД хранится только SHA-256 и безопасный снимок, TTL 24 ч, 10 чтений, отзыв, лимит 30 запросов с IP за минуту. Публичная ссылка только для чтения, без входа. Остальные API требуют сессию; POST защищены CSRF, общий лимит размера тела сохранен. Аудит включает только тип действия и slug без текстов и токенов. Новый шаблон nginx отключает access_log для /createportal/ctx/, а WSGI маскирует токен в журнале.

Карта строится из локального клона только при совпадении его origin с репозиторием проекта, без symlink и бинарных файлов; иначе из GitHub API через read-only token file. Кэш на час, максимум 3000 файлов. Без локального клона поиск индексирует первые 48 markdown-файлов GitHub с лимитами и флагом partial_index. Решения из DECISIONS.md, docs/DECISIONS.md и табличного docs/gdd/DECISIONS_APPROVED.md импортируются при синхронизации плана и открытии памяти. Модули ядра не переписаны. В UI добавлены «Контекст для ИИ» на доске и в «Ещё», предпросмотр, выбор ролей, копирование, системное «Поделиться», ссылка с отзывом, экран «Память» с поиском, фильтрами, решениями и картой репозитория.

## Допущения
1. PORTAL_MEMORY=1 по умолчанию по специальной спецификации; PORTAL_MEMORY=0 выключает.
2. Неизвестный или чужой локальный clone недоверенный. Предпочтён GitHub API при отсутствии валидного клона.
3. Для больших репозиториев индекс документов ограничен первыми 48 markdown-файлами и помечается partial_index; приватный репозиторий без read-only токена может не индексироваться.
4. «Одноразовый токен» трактуется как уникальный секрет одной выдачи URL; сама ссылка допускает до десяти чтений в 24 часа. При требовании строго одного чтения следует отдельно изменить лимит.
5. «Сквозной тест на реальном сервере» выполнен на VPS Lunex, в изолированном тестовом HTTP-процессе и временной БД; production сервис и его БД не менялись.
6. Для Chromium временно распакованы недостающие зависимости в /tmp/a9-browser-libs. Системные пакеты не устанавливались, прочие сервисы не трогали.
7. В текущем main отсутствует docs/gdd/13_*.md; для A9 применена отдельная спецификация docs/portal/13_MEMORY.md.
