# Проверка APK на собственном Android

## Скачивание с сайта игры
**Основная ссылка:** https://rikagro.ru/lunexeconom/

Кнопка «Скачать APK» загружает актуальную тестовую сборку непосредственно с VPS:
https://rikagro.ru/lunexeconom/Bashkiria-Honey-Oil-debug.apk

Не нужно заходить в GitHub Actions и распаковывать ZIP.

## Автоматическая доставка
1. После изменения клиента GitHub Actions собирает debug APK, проверяет подпись, архитектуры и ZIP-целостность.
2. Успешный workflow обновляет отдельный prerelease `android-test-latest` в GitHub Releases. **Это только тестовый канал, не утверждённый публичный релиз.**
3. VPS-таймер каждые ~5 минут проверяет release, скачивает APK, проверяет размер, ZIP и AndroidManifest.xml, вычисляет SHA-256.
4. VPS атомарно обновляет `Bashkiria-Honey-Oil-debug.apk` и `release.json`. При ошибке прежняя версия остаётся доступной.

APK подписана **debug-подписью** и не проверена на физическом устройстве. Для обновления Android-приложения поверх предыдущей версии подпись должна совпадать; если ключи от разных GitHub-hosted runners отличаются, потребуется удалить предыдущую тестовую установку, потеряв её локальные данные. Для стабильных обновлений нужен постоянный release signing key.

## Проверка
Установить APK, проверить горизонтальный режим, safe area, запуск, управление, возврат из фона и сетевые ошибки. Прислать скриншот или описание проблем. Текущая ранняя версия является техническим прототипом.

## Ограничения
- Firebase Test Lab остаётся выключенным до согласования расходов.
- Эмулятор отключён, проверку на телефоне выполняет пользователь.
- Подтверждённый GitHub Release требует отдельного отчёта из `docs/device-tests/README.md`.
