# ChatGPT8: regions benchmark and Godot render (15.11.2026)

## Результаты
- `tools/benchmark_regions_overview.py`: временная SQLite, 20 регионов × 3 продукта, 120 прогонов каждого метода; **старый per-region fetch: 20 SQL, median 0.1231 ms**; **новый batched fetch: 1 SQL, median 0.0564 ms**, ускорение **2.18×**. Результаты выборки сравнивались на равенство. **Измерена только часть `regions.overview`, не полный HTTP endpoint**.
- `client/qa/capture_model.gd`: Godot 4.7.2 под Xvfb, отдельная 960×540 сцена с factory.glb, камерой, светом. PNG успешно записан в `/tmp/chatgpt8_factory_qa.png` (5800 байт), Godot завершился с exit 0. Вторая попытка без ошибок движка. **Скриншот визуально не утверждён**, он остаётся локальным тестовым артефактом, не частью git.
- Скрипт использует только локальную сцену без подключения к игровому серверу.

## Не завершено
Полноценный тест 200 одновременно аутентифицированных игроков и операций, PostgreSQL конкурентные покупки/продажи в разных городах, HTTP ошибки oil_well/no_deposit/deposit_busy, оценка уникальности 3D моделей, реальный screenshot главного UI, удалённый GitHub Actions run. Основные производственные сервисы не менялись.
