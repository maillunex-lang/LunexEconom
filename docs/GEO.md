# География Башкортостана в LunexEconom (ChatGPTTwo, раунд 3)

## Назначение и ограничения

20 центров составляют **игровые регионы** по крупнейшим городам Республики Башкортостан, а НЕ официальные муниципальные районы. Официальные муниципальные границы/названия этим не заменяются. Метки жителей являются приблизительными справочными оценками по состоянию на 2024 год. Игра не пытается воссоздать реальные улицы или жилые кварталы.

Имена центров: Уфа, Стерлитамак, Салават, Нефтекамск, Октябрьский, Белорецк, Сибай, Мелеуз, Кумертау, Туймазы, Ишимбай, Бирск, Белебей, Дюртюли, Баймак, Учалы, Давлеканово, Благовещенск, Агидель, Янаул. Численность, широта, долгота, специализация и идентификатор указаны в `server/geo.py`. Для первичной сверки использованы данные Росстата и открытые географические справочники: [Росстат, «Численность населения ... по муниципальным образованиям», 2024](https://rosstat.gov.ru/), [города и географический справочник](https://your-online.ru/coordinates/ru/respublika-bashkortostan), [городской контекст Башкортостана](https://visit-bashkortostan.ru/goroda-bashkortostana/). Все численности обозначаются **«оценка»**, они не являются точной переписью.

## Модель мира и координаты

Уфа привязана к клетке **(0,0)**. Географический масштаб **3 клетки ≈ 1 км**. Проекция: широта смещается на 111,195 км/градус; долгота примерно на 111,195 × cos(широты Уфы) км/градус; координаты округляются. Центр на воде заменяется ближайшей сухой клеткой в пределах 25 клеток по детерминированному порядку. Уфа–Стерлитамак по прямой ≈124,4 км, тест проверяет 120–130 км. Радиусы городских фоновых территорий задаются формулой от оценки населения в `geo.city_area`.

**Запрещено изменять** `roads.is_water`, `roads.is_base_road`, `roads.terrain_noise` и копию рельефа `world.gd:cell_kind`. География и застройка только рисуются поверх действующего мира и не запрещают новые постройки.

## Трассы, расстояния, население

Из 20 городов строится минимальное остовное дерево по расстоянию Хаверсина, плюс 8 наиболее коротких дополнительных связей. Итого **27 рёбер**. Каждое прокладывается по сухим существующим клеткам посредством детерминированного A* с восемью направлениями, обходя воду. Это **фоновые трассы**, не игровые дороги игроков; строительство и авторитетные клетки имеют приоритет. Длина маршрута = сумма ортогональных шагов по 1 клетке и диагональных по √2, делённая на 3; скорость для будущей логистики условно 1 800 км/игровой месяц; `travel_months = max(0.01, round(road_km/1800, 3))`. Это справочная оценка, не тариф и не игровая перевозка.

`geo.population(city, month_index)` меняет справочную численность медленно (фиксированный по seed тренд от -0,2‰ до +0,2‰ в месяц), диапазон 80–120% базовой оценки. Модель независима от БД и не влияет на `production.py`, `city.py`, спрос, зарплаты или бюджет. Клиент читает параметр `monthly_growth_permille`.

Список улиц и кварталов различен по детерминированному порядку в каждом городе (`geo.streets`). `geo.plot_address` создаёт формат «Уфа, ул. …, 6:3». Это **генерация названий для игрового мира**, не реальные адреса. Каждый город имеет уникальные названия в своём наборе.

## REST API

`GET /geo/regions` → `{"regions":[...]}`; `GET /geo/cities` → `{"cities":[...]}`, включая население, радиус, координаты, улицы; `GET /geo/routes` → `{"routes":[...]}` с длинами, временем и сухими клетками. Авторизация не требуется, `Cache-Control: public, max-age=3600`. Остальные маршруты и форматы /world, /wallet не изменяются.

## Android / Godot 4.7.2

`regional_map_panel.gd` и `regional_map_canvas.gd` дают экран «Карта» из «Меню»: 20 городов, условные зоны, связи, перетаскивание, щипок, выбор, карточку, кнопку «Перейти». Панель ограничена `host.panel_rect()`, фиксирует заголовок, текст в ScrollContainer, скрытая панель не принимает касания. JSON загружается через существующую сетевую обёртку один раз, затем локально кэшируется в `user://`. При ошибке сети выводится сообщение.

`city_layout.gd` создаёт детерминированные кварталы/площади/фоновую промышленную зону. `chunk_renderer.gd` отрисовывает только активные 12×12 чанки, при удалении домики скрываются уровнем детализации. Вода, деревья, игровые дороги и здания всегда перекрывают фоновую генерацию. При отсутствии данных `/geo/*` основной мир продолжает работать.

`season_visual.gd` применяет оттенки зимы/весны/лета/осени по серверному игровому месяцу. Отключение сезонной окраски сохраняется в `user://season_effects.txt`. `perf_overlay.gd` по кнопке FPS показывает FPS, время process-кадра, число активных чанков и ориентировочное время перерисовки чанков. Это **не** GPU-профиль и **не** измерение на телефоне.

## Открытые решения

Не вводить ограничения на строительство в зоне города и не переписывать формулу игрового рельефа без решения владельца. Бизнес-правила для разных городов, региональных рынков и логистики пока не реализованы. Для настоящего APK проверить на Android safe area, жесты карты, фактический FPS и тепловую нагрузку; headless-смоуки не равнозначны испытанию на устройстве.
