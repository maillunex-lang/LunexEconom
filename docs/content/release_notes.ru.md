# Заметки «Что нового» для update.json

## Шаблон

Что нового в версии X.Y.Z:

- Коротко, что изменилось для игрока.
- Без технических слов.
- До 300 символов.

## Правила

Пиши:
- Что стало лучше для игрока.
- Какие новые возможности.
- Что починили (простыми словами).

Не пиши:
- Названия файлов, кода, серверов.
- Обещания заработка.
- Технические термины (API, SHA, versionCode и т.п.).
- Длинные списки.

## Примеры (каждая до 300 символов)

### Пример 1
Исправлена ошибка при входе после перезапуска телефона. Теперь аккаунт сохраняется надёжнее. Добавлена подсказка о границе месяца в 09:00 по Уфе.

### Пример 2
Магазин теперь показывает продажи по ячейкам. Можно быстрее понять, какой товар лучше продаётся. Починили списание денег при стройке.

### Пример 3
Улучшена загрузка карты города. Участки открываются быстрее. Добавлено напоминание о запасах на складе.

### Пример 4
Починили поставку зерна с поля на мельницу. Теперь связь работает стабильнее. В штабе обновляется баланс сразу после продажи.

### Пример 5
Новый экран отчёта за день. Видно, сколько произвели и продали. Исправлена ориентация при повороте телефона.

### Пример 6
Ускорена докачка обновления при обрыве связи. Прогресс сохраняется. Добавлена проверка, что данные не пропали после установки новой версии.

Все примеры короткие и понятные владельцу, который проверяет на телефоне.
