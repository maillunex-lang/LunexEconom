# EX-03: земельный реестр, собственность, аренда и торги

Дата: 15.11.2026. Реализация в ветке `ChatGPT12`. Сервер остаётся источником истины, схема SQLite/PostgreSQL одинакова; **боевой сервер не обновлялся**.

## Включение, совместимость и миграция

- `LAND_ENABLED=0` (по умолчанию): старый `POST /build` по-прежнему проверяет `cells`, `roads`, `zoning`, но **не** требует покупки земли. Старый экономический симулятор не меняется.
- `LAND_ENABLED=1`: `POST /build` в обеих реализациях SQLite/PostgreSQL проверяет собственность/аренду **по каждой клетке footprint**. Старые здания продолжают работать без перерегистрации производства.
- `land.ensure(db, ph)` подключён одной точкой в `game_server._prepare` и `postgres_db.init`. Использованы `CREATE TABLE IF NOT EXISTS`, отсутствие массового создания миллиардов участков: объект создаётся лениво при обращении к зоне.
- Перед покупкой, строительством и при месячном расчёте `land.migrate_existing` **не удаляет здания, дороги или кошельки**. Существующие объекты определяют владельца пересечённых участков 6×6. Если у одного участка несколько старых владельцев, применяется `legacy:shared`, сохраняются права на старые объекты, но новый участок не выставляется на свободную продажу автоматически.
- Не запускать `citygen --apply --wipe`. Перед включением на живом мире: резервная копия, миграция на копии БД, проверка владения/кошельков, отдельное согласование владельца игры.

## Модель

- Клетка игры: 20×20 м, участок: **6×6 клеток** (120×120 м, 14 400 м²). Ключ участка `px:py`, `px=x//6`, `py=y//6`; отрицательные координаты используют математическое округление вниз.
- Центр/жилой район/промзона определяется `zoning.zone_at`; «open» вне городской зоны. Внутри города базовый владелец `municipal:<city_id>`, вне города `state`. Владелец может стать обычным игроком или NPC-компанией.
- Рыночная стоимость (целые игровые ₽): `regional_prices.market_price_m2(city_id) × 14 400 × zone_permille / 1000` с округлением. Коэффициенты в `land.py`: центр 40‰, пригород 18‰, промзона 12‰, свободная земля 5‰. Цены жилья города различаются по Башкортостану.
- Фиксированную цену может назначить действующий мэр только муниципальной земле; она используется вместо оценки, пока режим `price_mode=fixed`.
- Платная аренда общественной земли: **1% оценочной стоимости за игровой месяц**, от 1 до 120 игровых месяцев; первый месяц оплачен при подписании, затем одна проводка в каждый месяц, оплата идёт муниципалитету либо казне. При нехватке средств договор прекращается. Двойное начисление исключает таблица `land_lease_payments`.
- Владелец частного незастроенного участка платит **0,1% его стоимости в месяц** в бюджет города; недоплата учитывается в `land_tax_arrears`. Участки `state`, `municipal:*`, `town:*` и общие старые участки не облагаются этим налогом.
- Регулируемый выкуп: только после отдельного авторизованного согласия нынешнего землевладельца `/land/buyback/consent`, срок согласия 3 игровых месяца. Сумма = оценка +10%. Мэр оформляет выкуп, с бюджета города уходит ровно одна сбалансированная проводка; переданный в теле запроса текст «согласен» **не** считается согласием.

## Аукционы

Мэр города открывает лот муниципальной свободной земли через `/auctions/create` (1…12 месяцев). Цена старта равна оценке участка, шаг ≥5% цены старта. После открытия статус участка `auction`, поэтому `/land/buy`, `/land/lease` и вторые торги не проходят. Занятая зданиями земля также не выставляется.

Каждая ставка блокируется общей транзакцией мира (SQLite `BEGIN IMMEDIATE`, PostgreSQL `pg_advisory_xact_lock(20261114)`). Ставка переводится в `system:land_escrow`; предыдущему лидеру деньги возвращаются той же сбалансированной проводкой. Победитель и собственность переходят вместе при закрытии срока, средства уходят муниципалитету. При отсутствии ставок участок возвращается на свободную продажу. `/auctions/cancel` возвращает обеспечительную ставку и статус участка; отмена после срока не разрешена. Мэр не может торговаться за выставленные муниципальные участки.

`request_id` обязателен (UUID); ответ успешной команды хранится в существующей таблице `commands` с ключом `(owner,request_id)`. Повтор команды возвращает оригинальный результат без повторных проводок.

## API

Все маршруты закрыты Bearer-авторизацией игрового аккаунта. Состояние при выключенном флаге: мутации отвечают HTTP 404 с `feature_disabled`. Цифры и цены возвращаются целыми игровыми ₽.

| Метод | URL | Тело / параметры | Результат |
|---|---|---|---|
| GET | `/land?cx=0&cy=0` | чанк 12×12 клеток | `enabled`, `parcel_size`, `parcels[4]` с собственником, статусом, ценой и арендой |
| POST | `/land/buy` | `px`, `py`, `request_id`, необязательно `max_price` | `parcel_id`, `owner`, `price` |
| POST | `/land/lease` | `px`, `py`, `months`, `request_id` | `rent_month`, `lease_until` |
| GET | `/auctions` | нет | список торгов и ставок |
| POST | `/auctions/create` | `px`, `py`, `months`, `request_id` | `auction_id`, `start`, `min_step`, `closes_month` |
| POST | `/auctions/bid` | `auction_id`, `amount`, `request_id` | подтверждение ставки |
| POST | `/auctions/cancel` | `auction_id`, `request_id` | сумма возврата и `cancelled` |
| POST | `/land/rezone` | `px`, `py`, `zone`, `request_id` | `application_id`, `pending` |
| POST | `/land/rezone/decide` | `application_id`, `approve`, `request_id` | `approved`/`rejected` (только мэр) |
| POST | `/land/fixed-price` | `px`, `py`, `price`, `request_id` | новая фиксированная цена (0 снимает режим) |
| POST | `/land/buyback/consent` | `px`, `py`, `request_id` | цена и срок согласия собственника |
| POST | `/land/buyback` | `px`, `py`, `request_id` | городской выкуп при наличии согласия |

**Примеры**, `request_id` всегда уникален на новую операцию:

```json
{"px":0,"py":0,"max_price":2500000,"request_id":"56db0f00-9800-4f00-8000-000000000001"}
```

```json
{"auction_id":"<id из GET /auctions>","amount":2100000,"request_id":"56db0f00-9800-4f00-8000-000000000002"}
```

HTTP 400 означает неверные поля, 401 нет авторизации, 402 недостаточно средств, 403 нет полномочий, 409 конфликт собственности, зоны или ставки.

## Таблицы

- `land_parcels`: координаты, город/зона, владелец, статус, цена, арендатор и сроки.
- `land_auctions`, `land_bids`: торги, ставки, блокирование, победитель.
- `land_rezones`: заявки и решение мэра.
- `land_legacy_buildings`: сопоставление старых зданий с участками; старые `buildings` и `cells` не меняются.
- `land_months`, `land_lease_payments`, `land_tax_arrears`: месячная идемпотентность, оплата аренды и долг по налогу.
- `land_buyback_consents`: авторизованный выкуп.

## Ограничения и передача смежным блокам

Это первая серверная версия; графического окна земли на Android пока нет (EX-11). Нет вторичного P2P-рынка перепродажи участков, дробления/слияния, отдельного госарбитража и кадастровых обременений. Смена назначения участка влияет на новые строительные проекты через земельный реестр, но не переписывает геометрию публичной карты `zoning.zone_at` и не разрешает автоматически любое строительство через старый `POST /build`. Долгосрочные права арендаторов на здания после окончания договора требуют отдельного согласования с юридическим блоком.

Серверный хук в `GET /hq` / окно земли сможет брать `land_parcels`, `land_auctions`, `land_tax_arrears`. Финансы идут только через `economy.post`.
