# ChatGPT8: HTTP deposits + PostgreSQL concurrent trading (15.11.2026)

## HTTP строительство нефтяной скважины
`tools/http_deposits_build.py` запущен против отдельного loopback HTTP сервера с временной SQLite мира и авторизации. Использован тестовый Bearer token. Все ожидаемые ответы подтверждены:
- Вне залежи, но с дорожным доступом: **409 no_deposit**
- На свободной нефтяной залежи: **201**
- На другой залежи, уже связанной с активным зданием через тестовую фикстуру: **409 deposit_busy**

Тестовая фикстура для busy вставлена только в одноразовую SQLite БД; production не затронут.

## PostgreSQL 16 concurrent matching
Изолированный `lunex_ci` на loopback порту 15499 в одноразовом Docker контейнере, миграции 001–004.
- 2 параллельные заявки продажи 10 honey при складе 10: **201 + 409**; после резервирования склад 0, резерв 10.
- 2 параллельные покупки по 7 honey при доступном sell order на 10: **201 + 201**, реально исполнено суммарно **10**, остаток склада покупателей **10**, резерв **0**.
- Несбалансированных бухгалтерских транзакций: **0**.
- Повторный запуск теста очищает только тестовые `chatgpt8_%` inventory и тестовые orders/fills внутри отдельной БД. Контейнер удалён по окончании.
