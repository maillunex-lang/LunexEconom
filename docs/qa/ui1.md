# V2-UI-1: отчёт и допущения

Реализуется в `v2/ui-implementation-1`; в main и VPS не вносится. В основе: GDD 26, предложенные токены Forest Glass, безопасная зона из `DisplayServer.get_display_safe_area()`, полноэкранный фон и content `MarginContainer` в `main.gd` (без повторного обёртывания).

## Реализовано

- Совместимая тема Forest Glass: scale `clamp(min(width/1280,height/720),1,1.5)`, минимальный target 48, состояния Button; существующие цвета, используемые другими экранами, сохранены.
- Общие UI helpers `components.gd`: кнопки трёх типов, поле с ошибкой, карточка, переносимая раскрывающаяся подпись, пустой список с действием, загрузка/повтор, подтверждение; `toast.gd` с автоскрытием 3.5 с; `two_columns.gd` с порогом ширины 1600.
- Экран входа: сохраняет login/register, сигналы и ссылочные поля для `main.gd`, фон полностью покрывает viewport, широкая раскладка бренд+форма, карточка до 720 px, прокрутка при клавиатуре, переключение видимости пароля, блокировка кнопки в ожидании ответа.
- Экран обновлений: фон на весь viewport, ограниченная ширина содержимого, переключение единственного основного действия, версия, примечания из подписанного манифеста (`notes`), размер файла, Wi-Fi toggle, текущий progress; отображаемые ошибки безопасности стали понятными без изменения криптографии.
- Строки согласованы через `tools/build_strings.py`.

## Принятые допущения

- Установленный `canvas_items + expand` и sensor landscape в `client/project.godot` не меняются, так как это правильный режим для 21:9.
- Для `main.gd` уже существовали полноэкранный background и единственный safe-area `shell`; реиспользуем их, а не строим вторую оболочку.
- Двухколоночный master-detail предоставлен компонентом для будущих экранов; вход использует более уместную бренд/форма раскладку. Карта, штаб, предприятия и настройки остаются в зоне следующих этапов.
- Текст версии `version_code` в случае отсутствия отдельной строки версии текущей APK показывает числовой код без выдуманного номера релиза.
- Сеть и релизное API в этих проверках не подменяются; заметки читаются из `notes` уже проверенного манифеста.
