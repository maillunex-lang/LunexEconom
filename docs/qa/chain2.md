# V2-CL-CHAIN2: новый каталог в клиенте

## Допущения CHAIN2

- Названия товаров, зданий, единицы и эталонные цены берутся только из `GET /catalog` с кешированием ETag. При неизвестной единице: «ед.», `kg`: «кг», прочие единицы из самого каталога.
- Поле `materials_required` является сигналом включённого серверного флага; при его отсутствии блок отсутствует. `short` принимается в обоих форматах: массив строковых ID и массив объектов с `product_id` (реальный серверный контракт).
- `GET /enterprises/plan` может не присылать `materials_required`; тогда дополнительных строк нет. Не рассчитываем нормативы локально.
- Старый утверждённый шаблон `build.material.stage` содержит «шт.»; не правим `docs/content`, вместо него используется шаблон `client/data/enterprise_strings.json`. Утверждённые ключи предупреждений остаются в `client/data/strings.json`.
- Специализация розницы: пересечение `allowed_goods` каталога здания и ответа ячеек, если каталог доступен; цены только серверные.
- Неизвестная категория получает русскую подпись «Прочее», а её внутренний ID сохраняется при фильтрации.
- Изменение не затрагивает вход, обновление, навигацию, обучение, сервер, web и ops.

## Реализовано

- В карточке стройки отображаются серверные нормативы и остатки по единицам из каталога, выделяется дефицит, показываются предупреждения из утверждённых русских строк. Отсутствие `materials_required` оставляет блок скрытым. Поддерживаются оба вида `short`.
- Выбор здания поддерживает 42 элемента с прокруткой и фокусом, сохраняет ID фильтра даже для неизвестной категории («Прочее»). Суммы и стоимость берутся из данных сервера и форматируются через `Format`.
- Розница обнаруживается по `role: retail` из серверного каталога, без перечня зданий и `kiosk`. В магазине используется `allowed_goods`, видны серверные имена товаров, сохранённая цена либо эталон `reference_price` из каталога и эталонная подпись. Существующие параметры ячеек и API сохранены.
- Проверен мок-каталог с 41 товаром, 42 зданиями, 41 рецептом; новые категории и АЗС; отсутствие/дефицит/наличие стройматериалов; оба формата `short`.
