- Флаг `supply_sales_modes_enabled=false` сохраняет прежний вход в `supply_links` и `supply_market` и порядок существующих тиков.

## Допущения

1. Достоверный `beneficial_owner_id` пока отсутствует: группировка холдинга временно выполняется по `enterprises.owner_id`, без графа дочерних юридических лиц. Разделение по разным игровым аккаунтам этим этапом не выявляется.
2. Заявка на договор создаётся продавцом, без второй подписи покупателя и без договорных штрафов. Резерв ограничен текущим запасом и остаётся в строке договора, а не в отдельном складе. Согласование договоров двумя сторонами требуется отдельным заданием.
3. Все параметры на этапе баланса считаются `draft`. Значения рейтинга и веса сохранены как в эталонном `tools/sim/sales/model.py`; допуск по географическому расстоянию определяется доступным `world.routes`, а внешняя портовая альтернатива применяется только при включённом порте.
4. Маршрут собственного перемещения выполняет 0 ₽ товарной выручки; межгородская доставка и топливо по-прежнему оплачиваются покупателем.
5. Функция `city_gas` является внешним модулем вне зоны текущего задания. При включённом флаге запрет приватных продаж должен также применяться к коммунальным закупкам газа до включения в продуктивном мире. До исправления обхода — **не активировать флаг на продуктиве**.

## Остаточные ограничения и ревью

- Приглашения хранятся одним текущим набором `sales_invites`: их изменение не версионируется по дням. Для безопасной смены списка приглашённых в уже действующем режиме нужен отдельный этап.
- Лимит 40% вычисляется относительно предложения отдельного продавца/товара; покупатели объединяются по `owner_id`, но не по юридическому графу холдинга. Сквозной муниципальный лимит по всем продавцам не реализован.
- `GET /supply/quotes` возвращает указание на `GET /supply/offers`, а не отдельную таблицу рейтингов.
- Полноценный конкурентный стресс-тест нескольких одновременных COMMIT и производственных тиков не выполнен; в коде используются SQL-блокировки.
- До согласования `city_gas` с политиками продаж включение feature flag в продуктивном мире не рекомендовано.
