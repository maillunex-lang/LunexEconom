# GDD 39. Внешняя торговля: порты, импорт, экспорт, пошлины

**Статус:** проект директора (2026-11-16), **balance: draft**. Симулятор `tools/sim/wave4/` (раздел trade). Волна 4.

## 1. Идея
Внешний рынок ограничивает цены сверху и снизу и спасает от дефицита и излишков. Он работает через порты (в игре уже есть `supply_port_city_draft`) и не заменяет игроков.
```
import_price = ref * (10000 + import_premium_bp) // 10000 * (10000 + tariff_bp) // 10000
export_price = ref * (10000 - export_discount_bp) // 10000 * (10000 - tariff_bp) // 10000
effective   = clamp(domestic, export_price, import_price)
```
Для эталона 38 ₽, премии импорта 40 %, скидки экспорта 25 % и пошлины 5 %: импорт 55 ₽, экспорт 26 ₽. Внутренняя цена выше 55 ₽ превращается в импорт, ниже 26 ₽ в экспорт, между ними торгуют игроки.
## 2. Порты и объёмы
Типы: промышленный (экспорт сырья, импорт оборудования) и торговый (потребительские товары). Объём порта в сутки ограничен (по товару, в единицах), поставка идёт с задержкой по расстоянию, логистику платит покупатель (GDD 28, 43). Пошлины поступают в `system:tax`.
## 3. Правила
Импорт не заменяет внутреннее производство целиком: квота на товар в % спроса города (по умолчанию 30 %); экспорт только излишков, продаваемых из склада предприятия; игроки видят цены порта публично как ориентир потолка.
## 4. Серверная часть и решения
Таблицы `port_prices`, `port_orders(request_id, side, product, qty, price)`, суточный пересчёт цен порта, флаг `foreign_trade_enabled`. Решения: премия, скидка, пошлина и квота правятся в A3; рекомендация владельцу: включать после пересмотра баланса (GDD 36), иначе порт искажает цены.
