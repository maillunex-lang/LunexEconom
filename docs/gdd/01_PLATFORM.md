# GDD 01. Платформа

**Цель:** фундамент, на котором работают все модули: аккаунты, учёт денег, часы и тик, настройки, администрирование.

## Сущности и правила
- **Аккаунт:** имя (3–24 символа, без `:`), email, пароль (хеш с солью, медленная функция), роль `player|developer|admin`, статус (активен, забанен). Сессии с коротким токеном доступа и обновляемым токеном; ограничение попыток входа; выход; запоминание входа на устройстве.
- **Учёт денег (`ledger`):** счета (`player:<имя>`, `company:<id>`, `city:<id>`, `system:treasury|market|bank|upkeep|...`), проводки с несколькими строками, **сумма строк всегда 0**, целые рубли, идемпотентность по `request_id`. Баланс кошелька не уходит в минус кроме явно разрешённых системных счетов. Запрет прямого изменения баланса, только проводками.
- **Игровые часы и тик:** по ADR-001; реестр обработчиков с порядком; догон пропущенных дней; идемпотентность по `day_index`; замер времени; откат дня при сбое обработчика.
- **Настройки и флаги:** значения по умолчанию → окружение → база; ревизии с откатом; применение параметров расчёта месяца с начала следующего месяца; публичный подписанный клиентский конфиг.
- **Присутствие:** кто онлайн, версии клиентов.
- **Админка:** состояние сервера, онлайн, флаги, параметры, журнал действий; только с loopback и токеном; публичной записи нет.
- **Обновление клиента без APK:** подписанные патчи контента (картинки, 3D-модели GLB, тексты), клиентская конфигурация; код клиента меняется только новым APK.

## API (ядро)
`POST /auth/register`, `/auth/login`, `/auth/refresh`, `/auth/logout`, `GET /me`, `GET /health`, `GET /config`, `GET /clock`; `/admin/*` только админка.

## Данные
`accounts`, `sessions`, `ledger_accounts`, `ledger_tx`, `ledger_entries`, `game_ticks`, `settings_*`, `presence`, `audit`.

## Приёмка
Регистрация и вход, ограничения; проводки сходятся (тест на случайных операциях, 10 000 проводок, сумма 0); два одновременных перевода без двойного списания (параллельный тест на PostgreSQL); тик догоняет 3 пропущенных дня идемпотентно; флаг из админки меняет поведение без перезапуска; подпись конфига проверяется клиентом.
