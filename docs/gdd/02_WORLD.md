# GDD 02. Мир и карта

**Цель:** географическая основа: 20 городов Башкортостана, карта клеток, дороги, зоны, земля.

## Города
20 городов по реальным координатам и населению (Уфа, Стерлитамак, Салават, Нефтекамск, Октябрьский, Белорецк, Сибай, Мелеуз, Кумертау, Туймазы, Ишимбай, Бирск, Белебей, Дюртюли, Баймак, Учалы, Давлеканово, Благовещенск, Агидель, Янаул). У города: центр, радиус, специализация, население (оценка), индексы цен (стоимость строительства, цена жилья и земли, зарплаты) относительно Уфы, трафик покупателей по районам. Цены: 1 игровой рубль = 50 реальных; опорные данные Уфы (новостройки 171 тыс. ₽/м², зарплата по республике 74 тыс. ₽).

## Карта
Сетка клеток (клетка = 20×20 м), чанки 12×12, координаты целые. Рельеф детерминированный (seed) плюс **правки** (редактор), одна река, деревья. Дороги: перекрёсток в центре каждого города, остальное строится подъездными путями, связность проверяется. Расстояния между городами по дорогам, время в пути = км / 85 км/ч в игровых часах.

## Зоны города
Центр, жилой район, промзона (клин во внешнем кольце), свободная земля. Правила, какие здания где (завод только в промзоне и т. д.), город растёт по мере застройки (радиус на 25 % за уровень, до 6).

## Земля
Участки 6×6 клеток. Владелец: город, государство, компания, игрок. Покупка, аренда, аукцион, смена назначения, налог на пустующую землю; цена по индексу города и зоне; защита от двойной продажи.

## API
`GET /world/cities`, `/world/routes`, `/world/chunk?cx&cy` (клетки, дороги, здания, участки), `/world/events?after` (изменения), `/land/...` (участки, торги).

## Данные
`cities`, `road_cells`, `terrain_edits`, `parcels`, `parcel_owners`, `auctions`, `events` с версиями чанков.

## Приёмка
Генерация мира детерминирована (одинаково на сервере и клиенте на выборке клеток); зоны запрещают здание не в той зоне; параллельная покупка одного участка проходит один раз; снимок чанка и поток событий синхронизируют двух клиентов.
