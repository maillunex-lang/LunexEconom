# GDD 26. Интерфейс клиента V2

**Статус:** proposal. Ветка `v2/ui-design`. Клиент не менялся. Числа целые. Проверка: `python tools/validate_ui_proposal.py`.

**Цель:** современный удобный интерфейс на весь экран телефона (Android, sensor landscape, 16:9–21:9, notch), без обрезанных надписей, с продуманной логикой кнопок и окон. Стиль Forest Glass.

## Допущения

1. Stretch mode остаётся `canvas_items` + `expand` (уже так в `client/project.godot`). Поля появляются из-за CenterContainer + фиксированных карточек, а не из-за stretch.
2. Safe area берётся через `DisplayServer.get_display_safe_area()` и `client/ui/safe_area.gd`. На 21:9 контент не вылезает в вырез.
3. Ошибки «Нет подписанного манифеста» и «Не удалось выполнить операцию» считаем текущими техническими сообщениями обновления/манифеста; заменяем на человеческие.
4. Финансы остаются заглушкой до серверного экрана.
5. Светлая тема опциональна, по умолчанию тёмная.
6. Макеты — чистый SVG, системный шрифт, без внешних ресурсов.

## 2. Система дизайна (токены)

Файл `client/theme/tokens_proposed.json`.

- Отступы: 4/8/12/16/24/32.
- Шрифты: caption 12, body 14-16, title 20, headline 24, display 28. Масштаб clamp(min(w/1280, h/720), 1.0, 1.5).
- Кнопки ≥48 dp высотой.
- Радиусы 8/12/18/24.
- Цвета Forest Glass тёмные (и светлые опционально). Роли: background, surface, accent, success, warning, error, text primary/secondary.
- Состояния: normal / pressed / disabled / focus.
- Анимации 120-250 мс, без бесконечных вне карты.
- Иконки: набор простых (back, close, check, warning, error, map, building, coin, settings, more, ai).

Контраст: текст ≥4.5:1, крупный ≥3:1. Проверяется в `tools/validate_ui_proposal.py`.

## 3. Компоненты

- **Кнопка основная:** accent bg, text dark, height ≥48, radius 12. Вторичная: surface. Опасная: error.
- **Поле ввода:** placeholder muted, error state red border + message under.
- **Карточка:** surface, radius 18, padding 16, max width на широких.
- **Список:** Scroll, empty state с иконкой + текст + CTA.
- **Вкладки:** HBox, selected accent.
- **Нижняя навигация:** 5 items, icon + label, safe bottom.
- **Диалог подтверждения:** модальный, title + text + Cancel/Confirm. Только для необратимых.
- **Тост:** внизу, 2-3 сек, success/error.
- **Индикатор загрузки:** spinner + текст «Загрузка...», кнопка Повторить.
- **Строка метрики:** label + value, monospace для чисел.
- **Значок статуса:** цветной кружок / badge.
- **Бейдж ИИ:** маленький «ИИ» для AI-игроков.

Текст: autowrap до 2-3 строк, затем ellipsis + expand on tap. Никогда не обрезать цену, сумму, название кнопки.

## 4. Правила вёрстки

- Фон на весь экран (за notch). Контент в safe area MarginContainer.
- Горизонтальный: на широких (≥1600) две колонки (список слева, детали справа); на узких одна.
- Карточка max width 720 на 21:9.
- Клавиатура: Scroll + ensure_control_visible, не перекрывать поля.
- Прокрутка вертикальная, horizontal disabled где не нужно.
- Минимум текста 12 dp.
- Автопроверка обрезки: headless Godot — пройти Label/Button, если autowrap=OFF и get_minimum_size > size — fail. Предложить тест в client/tests/.

## 5. Логика кнопок и окон

**Граф навигации:**
- Login → Headquarters (main)
- Nav: Headquarters ↔ Map ↔ Enterprises ↔ Finance ↔ More
- More → Settings, Updates, Logout
- Map → Build (выбор здания) → Confirm
- Enterprises → Enterprise card → Supply / Store
- Back: системная Android + кнопка «Назад» в header. Стек через router.
- Модальные: ConfirmationDialog, Updates (если mandatory).
- Подтверждения: только снос, продажа, отмена необратимая. Не для частых безопасных.
- Результат: тост или inline message.
- Ошибки: «Что случилось. Что сделать. [Повторить]». Без кодов.
  Замены:
  - «Не удалось выполнить операцию» → «Не получилось. Проверь связь и нажми Повторить.»
  - «Нет подписанного манифеста» → «Обновление не подтверждено. Попробуй позже или напиши в поддержку.»
  - «error.generic» → конкретное по коду или общее человеческое.
- Загрузка: spinner + текст.
- Пустые списки: иконка + «Пока пусто. [Действие]».
- Одна основная кнопка на экране.
- Глубина ≤3 шагов до любого действия.

## 8. Критерии приёмки

- Нет обрезанных подписей на 4 размерах (1280x720, 1920x1080, 2000x1200, 2400x1080).
- Касание ≥48 dp.
- Контраст ≥4.5:1.
- Ни одного бессмысленного сообщения из списка.
- Полный экран без чёрных полос.
- Back работает системно и кнопкой.
- Модальные только где нужно.

## Открытые вопросы владельцу

1. Светлая тема нужна сразу или только тёмная? Рекомендация: тёмная по умолчанию, светлая позже.
2. Две колонки на карте/предприятиях на широких? Рекомендация: да.
3. Бейдж ИИ где показывать? Рекомендация: на карточке предприятия и в списке.
4. Тосты или только inline? Рекомендация: тосты для успеха, inline для ошибок формы.
5. Макс ширина карточки 720 или больше? Рекомендация: 720.
