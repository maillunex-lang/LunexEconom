# GDD 04. Предприятия и производство

**Цель:** игрок строит и настраивает производственные звенья; они выпускают товар по суточному тику.

## Жизненный цикл
Участок → заказ строительства → **четыре стадии** (фундамент, каркас, отделка, ввод; общий срок = `build_months`, каждая стадия по доле срока) → работа → износ → снос или продажа. До ввода предприятие не производит и не платит зарплат, но платит за стройку по стадиям.

## Производство (суточный тик, обработчик `production`)
Для каждого работающего предприятия в день:
`загрузка = min(1, укомплектованность персонала, наличие сырья, свободное место на складе, технологический лимит)`.
`выпуск = выпуск_полной_загрузки × загрузка`; расход сырья пропорционален загрузке. Качество выпуска по `quality_model` рецепта. Выпуск идёт на склад предприятия.
**Персонал:** число работников ≤ `jobs`, зарплата по индексу города × базовая; нехватка работников в городе снижает укомплектованность (рынок труда по населению города, модуль 7); уровень персонала 1–9 (обучение, модуль 10).
**Склад:** ёмкость по товарам; при переполнении выпуск останавливается (нет порчи, если не задано в каталоге).

## Месячный шаг
Зарплаты, содержание, налог на имущество, износ (потеря технологического уровня без ремонта), отчёт предприятия: выручка, расходы, прибыль, загрузка, остатки.

## API
`POST /enterprises` (заказ строительства: тип, участок), `GET /enterprises`, `GET /enterprises/{id}`, `POST /enterprises/{id}/settings` (название, режим выпуска, минимальные остатки), `POST /enterprises/{id}/sell`, `GET /enterprises/{id}/report`.

## Данные
`enterprises`, `enterprise_state` (стадия, загрузка, персонал), `inventory` (предприятие, товар, количество, качество), `reports`.

## Приёмка
Построенная мельница получает зерно и выпускает муку за 10 дней по ожидаемому объёму; нехватка сырья снижает загрузку пропорционально; зарплата и содержание списываются проводками раз в месяц; продажа предприятия не оставляет висящих записей; баланс проводок 0.
