# GDD 41. Сценарии, цели, достижения и обучение

**Статус:** проект директора (2026-11-16), **balance: draft**. Волна 4.

## 1. Режимы
**Кампания-обучение** (8 коротких заданий), **песочница** (одиночный мир с ускорением времени x1/x10/x60, ИИ-игроки по выбору) и **основной мир MMO** (без сценариев). Тренажёрный режим не влияет на рейтинг основного мира.
## 2. Цели и достижения
Цель: `id`, условие (метрика из отчётов: оборот, число предприятий, прибыль, рейтинг), награда (косметика, звание, не деньги). Примеры достижений: «Первая прибыль», «Свой магазин», «Три поставщика», «Первая лицензия», «Выход на биржу». Награды только косметические (вариант A монетизации).
## 3. Кампания-обучение (порядок)
1) Купить участок. 2) Построить поле. 3) Подвести дорогу. 4) Построить мельницу и связать. 5) Магазин и цена. 6) Режим продажи. 7) Нанять сотрудника. 8) Первая прибыль. Каждый шаг проверяется сервером по метрикам (идемпотентно), подсказки на русском.
## 4. Песочница
Сервер-копия с отдельной базой, ускорение времени задаёт владелец песочницы, сброс одной кнопкой, без монетизации. В бете включается позже основного мира.
## 5. Решения владельца
Кампания в бете (да, 8 заданий), песочница после беты, награды только косметика.
