# Утверждённые решения владельца

Решения приняты владельцем проекта 2026-11-15 («все по рекомендации»). Источник вопросов и обоснований: `docs/proposals/DECISIONS.md` (ветка `v2/decisions`). Эти решения обязательны для заданий исполнителям и имеют приоритет над черновиками `docs/proposals/`.

| Код | Решение | Что это значит для разработки |
|-----|---------|-------------------------------|
| D-04 | Платежи покупателей в магазине идут со счёта `system:market`. | Модуль розницы (V2-06) списывает покупки через этот системный счёт; отдельный счёт домохозяйств не нужен. |
| D-18 | Цена на полке включает НДС, ставка потребительских товаров 1000 bp (10 %). | База = выручка × 10000 // (10000 + vat_bp); НДС = выручка − база; платит компания в `system:treasury` в месячном шаге. Поле `vat_category` каталога получает ставку. |
| D-10, D-53 | Стройка в 4 стадии (фундамент, каркас, отделка, ввод), оплата ЧАСТЯМИ по стадиям. | Текущая реализация `enterprises` списывает всю сумму сразу: нужна доработка (платёж при входе в каждую стадию, идемпотентный `request_id` на стадию, при нехватке денег стадия не наступает и стройка стоит). Отдельное задание. |
| D-55 | Просрочка останавливает производство предприятия до погашения долга. | Уже реализовано в V2-04b. |
| D-51, D-52 | Порог роста города 6000 bp (60 % застройки), начальный радиус 12 клеток. | Уже реализовано в V2-03. |
| D-02 | Спрос считается по районам города. | Модуль 07: спрос делится внутри района, у района свой трафик и своё население; клиент показывает районы. Нужна привязка районов (`docs/content/city_districts*.ru.md`) к карте. |
| D-01 | Четыре слоя дохода населения. | Модуль 07: четыре корзины потребления. |
| D-49 | Нижняя панель навигации в клиенте. | Модуль 16: вкладки внизу экрана (штаб, карта, предприятия, финансы, ещё). |
| D-50 | Обучение обязательно для новых игроков (первые 10 игровых дней). | Сценарий из `docs/content/tutorial.ru.md` включается при первом входе; можно пропустить только после завершения. |
| D-54 | Цена продажи здания игроком 50 % от `build_cost` (черновая). | Уже реализовано в V2-04. |

## Что из этого нужно сделать

1. **Оплата стройки по стадиям** (D-10, D-53): доработка `server/enterprises` (задание ChatGPT 1 после V2-05).
2. **Ставка НДС и база** (D-18): поле в каталоге и расчёт в модуле розницы V2-06.
3. **Районы города** (D-02): данные и привязка к карте до модуля 07.
4. **Нижняя навигация и обязательное обучение** (D-49, D-50): задания клиентской линии.
