## Реальный путь публикации

- Публичный манифест: `https://rikagro.ru/lunexeconom/assets/manifest.json`.
- Публичные PNG: `https://rikagro.ru/lunexeconom/assets/<имя_файла>`.
- Каталог на VPS: `/var/www/rikagro-game/lunexeconom/assets/`.
- World Studio: `https://rikagro.ru/lunexeconom/studio/`, раздел **Графика → Ресурсы Android-игры**.
- Код публикации: `admin_studio/game_asset_upload.py`, `admin_studio/server.py`, `admin_studio/static/game-art.js`. Публикация допускает только пять разрешённых имён, проверяет PNG, делает резервную копию и обновляет SHA-256-манифест.

## Android-клиент

- `client/asset_downloader.gd`: HTTPS-манифест, SHA-256 через `HashingContext`, загрузка только разрешённых имён, кэш `user://downloaded_art/`.
- `client/test_sprite_visuals.gd`: текстуры из локального кэша; если кэш отсутствует, попытка чтения `res://assets/test_buildings/`.
- `client/chunk_renderer.gd`: текстура дороги; продуктовый магазин и жилые дома выбираются по типу и объекту; одинаковый `object_id` не должен отрисовываться многократно.
- Нет доступного изображения: используется процедурная графика. Изображения не встроены в APK.

## Проверено / не проверено

**Проверено 15.11.2026:** оптимизация в Godot 4.7.2 (около 10,8 МБ → 1,2 МБ); публичный манифест 5/5; Godot 4.7.2 headless загрузил все пять файлов по HTTPS, проверил хэши и прочитал их как текстуры; editor import прошёл без ошибок компиляции.

**Ещё не проверено:** новый APK на физическом Android; правильное наложение высоких домов и сортировка между чанками; полноценное строительство магазина 1×1. Существующие новые размеры строительства на сервере заблокированы до балансировки экономики. Графический скин сам по себе не создаёт новое предприятие.

Дальнейший план и критерии: [ROADMAP.md](ROADMAP.md), BE-100…BE-105.
