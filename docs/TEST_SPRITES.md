## Установка

Распаковать пакет `LunexEconom_test_sprites.zip` в корень проекта (сохранить каталог `client/assets/test_buildings/`). Спрайты содержат прозрачность, подготовлены для Android в PNG. В `client/test_sprite_visuals.gd` ресурсы подгружаются только если файлы существуют; без них остаётся прежняя процедурная графика.

Тестовые жилые дома визуально отображаются только для серверного `house`. Отдельного строительства жилых домов игроком в этой версии нет. Визуализация 2×1 зависит от `object_id` и фактических клеток объекта; при отсутствии информации о размере возможен процедурный fallback.

**Не считать этап внедрения завершённым:** в репозитории нет самих PNG до отдельной загрузки пакета; боевой сервер не обновлялся; новые размеры зданий пока заблокированы до балансировки экономики; Android APK не собран и не проверен.
