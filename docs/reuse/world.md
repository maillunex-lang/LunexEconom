# Задание: мир, чанки и события

**Источник:** `server/world/`, `client/world/`; тесты `server/tests/test_world_generator.py`, `server/tests/test_world_events_protocol.py`.

## Текст задания исполнителю

Изучи генерацию карты, координаты, чанки, кэш и обновление изменившихся клеток. Составь карту зависимостей сервер ↔ Godot, затем перенеси в новый проект только универсальные алгоритмы и протокол изменений. Реализуй детерминированную генерацию по seed, выдачу чанков, локальное обновление одной клетки и инвалидацию кэша. Тестируй порядок событий, повторную доставку, границы чанков и восстановление после переподключения. Не копируй города, координаты Башкортостана, изображения и серверные URL. Приёмка: зелёная CI, без скриншотов.
