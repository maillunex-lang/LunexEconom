# Задание: предприятия и торговля

**Источник:** `server/enterprises/`, `server/supply/`, `server/retail/`, `server/sales/`, `tools/sim/sales/`.

**Тесты-ориентиры:** `server/tests/test_enterprises_unit.py`, `server/tests/test_supply_math.py`, `server/tests/test_retail_unit.py`, `tools/tests/test_sales_sim.py`.

## Текст задания исполнителю

Разбери жизненный цикл предприятия, входное сырьё, производство, склад, поставщика, магазин и продажу. Явно раздели реализованный серверный код и автономные эталонные симуляторы. Для новой игры предложи минимальную сквозную цепочку «производитель → склад → доставка → магазин → покупатель», не перенося все системы сразу. Добавь тесты на запасы, частичную поставку, повторный запрос, цены и денежные проводки. Старые цены, баланс, модели предприятий и географию не считать обязательными. Работай только в новой ветке нового репозитория; приёмка зелёной CI.
