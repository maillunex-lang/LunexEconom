# Задание: ИИ-компании

**Источник:** `tools/sim/ai_engine/`, `tools/tests/test_ai_engine_sim.py`.

## Текст задания исполнителю

Изучи автономный прототип AI-компаний V2. Не предполагай, что он подключён к MMO-серверу. Выдели модель принятия решений, входные данные, ограничения бюджета, доступную информацию и детерминированность. Реализуй в новой игре минимального конкурента, который оценивает цены и спрос, принимает ограниченное число решений за тик и не может тратить несуществующие средства. Добавь тесты на одинаковый seed, дефицит бюджета, отсутствие выгодных действий и стабильность на многих тиках. Не подключай платные ИИ API без отдельного разрешения. Приёмка: зелёная CI.
