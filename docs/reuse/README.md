# Готовые задания ИИ для извлечения механик

Эти задания предназначены для **новой игры в отдельном репозитории**. LunexEconom V2 остаётся неизменяемым источником примеров. Сначала ознакомьтесь с [AGENTS.md](../../AGENTS.md) и [манифестом](../source_manifest.json).

## Порядок использования

1. Выбери механизм и открой соответствующий файл ниже.
2. Передай задание ИИ-исполнителю, указав **ссылку на репозиторий новой игры** и её стек.
3. ИИ сначала изучает код и тесты V2 в режиме чтения, затем составляет список переносимых файлов и зависимостей.
4. Изменения делаются **только в репозитории новой игры** и в отдельной ветке.
5. Приёмка: зелёная CI с тестами перенесённого модуля; без скриншотов.
