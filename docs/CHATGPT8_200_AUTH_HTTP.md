# ChatGPT8: 200 авторизованных игроков (15.11.2026)

## Выполнено
Запущен отдельный Python ThreadingHTTPServer на 127.0.0.1 и временные SQLite файлы мира и авторизации, без production базы/сервисов. В `tools/http_200_authenticated.py` создано 200 тестовых учётных записей и 200 независимых сессионных токенов (предзаполненные тестовые сессии, без дорогой регистрации и PBKDF2). Каждый пользователь запросил `GET /wallet` через HTTP.

- p95 **73.42 мс**
- Неуравновешенных проводок: **0**
- Сумма остатков всех кошельков: **0**
- Тестовый сервер завершён, временные файлы удалены.

## Границы результата
Это проверка **200 разных авторизованных пользователей**, но не 200 одновременных TCP-подключений. Все операции были GET /wallet, а не комплексные покупки/строительство/биржа. Тест не подтверждает масштабируемость боевого PostgreSQL сервера на 200 активных транзакционных игроков.
