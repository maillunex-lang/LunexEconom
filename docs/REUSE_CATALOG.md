# Каталог полезных решений для новой игры

Это **направления поиска**, не утверждения о готовности к переносу.

| Что искать | Где искать | Что проверить |
|---|---|---|
| Экономика и рецепты | `tools/sim/`, `server/catalog/` | Детерминизм, округление, тесты |
| Денежный учёт | `server/ledger/` | Идемпотентность, транзакции |
| Серверные тики | `server/clock/` | Игровое время, восстановление |
| Модульный сервер | `server/registry.py` | Контракты и миграции |
| Карта и чанки | `server/world/`, `client/world/` | Координаты, события, производительность |
| Производство | `server/enterprises/` | Ресурсы, здания, зависимости |
| Рынок и магазины | `server/supply/`, `server/market/`, `server/retail/` | Цены, остатки, контракты |
| Экономические эксперименты | `tools/sim/`, `tools/balance/` | Прототип или production |
| Android UI | `client/screens/`, `client/ui/`, `client/theme/` | Адаптивность, safe area |
| 3D Godot | `client/world/`, `client/models/` | Версия движка, права на ассеты |
| Обновления и контент | `client/update/`, `tools/build_packs.py` | Подписи, доверенные URL |
| Каталоги данных | `server/data/`, `tools/validate_catalog.py` | Схемы и ID |
| Тесты | `server/tests/`, `tools/tests/`, `.github/workflows/` | Окружение и зависимости |
| Портал для ИИ | `portal/` | Это отдельный продукт |

## Запрос для ИИ

> Используй LunexEconom V2 только как библиотеку исходников. Найди механику [название], перечисли точные файлы, зависимости, тесты и статус: код, прототип или только GDD. Предложи минимальный перенос в новый репозиторий. Не копируй исходный GDD, географию, секреты, боевые URL, миграции или инфраструктуру без отдельного решения. Если тесты не запускались, скажи об этом.

## Формат ответа
Механика; исходники; статус; зависимости; тесты; минимальный перенос; адаптация; риски.
