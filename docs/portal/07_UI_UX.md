# 07. Интерфейс и UX

## Принципы
1. Понятность с первого взгляда: на каждом экране видно «где я» и «что делать дальше».
2. У каждой кнопки подсказка (при наведении) и пояснение в панели задачи; кнопка «?» открывает справку по статусам и кнопкам (на телефоне наведения нет).
3. Опасные действия (приёмка, возврат из архива, сброс сеансов) требуют двойного нажатия или подтверждения, без системных диалогов.
4. Один основной экшен на карточку, остальные второстепенные (`ghost`).
5. Работает на телефоне с первого дня: боковые поля 16 px и безопасные зоны, кнопки не меньше 44 px, колонки схемы прокручиваются по горизонтали внутри контейнера.

## Дизайн-система
Токены: фон, поверхность, текст, приглушённый, линия, акцент (зелёный), предупреждение (янтарный), информация (синий), успех, ошибка; светлая и тёмная темы (системная настройка + переключатель, запоминается). Шрифты: Space Grotesk для заголовков, Inter для текста. Радиусы 12–16, мягкие тени на поверхностях. Цвета линий: A зелёный, B синий, C янтарный. Состояния кнопок: обычная, наведение, фокус (видимая обводка), нажата, отключена.

## Тексты
Русский, коротко, активный залог; кнопка называет действие («Отдал исполнителю», «Принято, в архив»); ошибки объясняют, что делать («Сначала нужно принять предыдущие шаги»). Никаких сырых кодов на экране.

## Доступность
Контраст не ниже 4,5:1 для текста; фокус виден; элементы доступны с клавиатуры (карточка открывается Enter и пробелом); панели имеют `role=dialog` и `aria-label`; кнопки без текста имеют `aria-label`; уважается `prefers-reduced-motion`; текст не обрезается, длинные слова переносятся.

## Состояния
Загрузка (пустой экран с индикатором не дольше 10 секунд, затем сообщение), пусто (с объяснением и кнопкой), ошибка (понятный текст), нет прав (v3), потеряна связь (баннер «Показано сохранённое»).
