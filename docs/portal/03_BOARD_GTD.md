# 03. Доска GTD, статусы, идеи, события

## Статусы задачи
`planned` (в очереди) → `issued` (у исполнителя) → `submitted` (сдано, ждёт приёмки) → `accepted` (принято, в архиве). «Можно выдавать» это не статус, а вычисляемый признак: `planned` и все зависимости `accepted`.

| Переход | Кто нажимает | Условия |
|---|---|---|
| planned → issued | владелец «Отдал исполнителю» | зависимости приняты (иначе 409) |
| issued → submitted | владелец «Исполнитель сдал» | — |
| submitted → accepted | владелец «Принято, в архив» | двойное нажатие; в v2 нужен чек-лист приёмки и зелёный CI |
| issued или submitted → accepted | **автоматически** (вебхук GitHub) | PR слит в основную ветку и CI на слитом коммите зелёный; можно выключить в настройках проекта; отмена кнопкой «Вернуть из архива» |
| issued → planned | «Вернуть в очередь» | сбрасывает отметки времени |
| submitted → issued | «Вернуть исполнителю» | на доработку |
| accepted → planned | «Вернуть из архива» | приёмка по ошибке |

Время каждого перехода (`issued_at`, `submitted_at`, `accepted_at`) хранится; у принятой задачи можно хранить `merged`, `sha`, `note`.

## Вид «Схема» (GTD) [v1]
Колонки: **Идеи** (входящие), **Очередь**, **Следующее**, **У исполнителя**, **Ждёт приёмки**, **Готово** (последние 5, остальные по кнопке «Весь архив»). Карточка: номер, название, линия (цветная полоска), шаг, «после X». Нажатие открывает панель задачи. Колонка «Следующее» выделена.

## Вид «По шагам» [v1]
Шаги сверху вниз, в каждом линии рядом; принятые скрыты. Для быстрого взгляда на порядок работ.

## Граф зависимостей [v2]
Шаги слева направо, стрелки зависимостей, цвет по статусу, линии на разных строках (макет `mockups/graph.svg`). Показывает критический путь и что блокирует что.

## «Что делать сейчас» [v1]
Список до четырёх действий для владельца, вычисляется из состояния: сданные задачи (ждать директора и принять), занятые линии (ждать отчёта), свободные линии с готовой задачей (взять промпт). Если плана нет, подсказка ведёт к «Старту проекта».

## Старт проекта [v1]
Два стартовых промпта (организация репозитория, полный GDD) с отметкой «Выполнено»; раскрыт, пока нет плана.

## Входящие идеи [v1]
Короткие заметки владельца (до 500 знаков, до 200 открытых на проект). Директор превращает их в пакеты плана; владелец отмечает «Учтено». [v2]: идея может быть превращена в черновик пакета кнопкой «Подготовить задачу для директора» (копирует промпт «Добавь эту идею в план по протоколу»).

## Лента событий [v1 в интерфейсе, v2 хранится]
Последние события: выдано, сдано, принято. [v2]: серверный журнал событий проекта с источником (владелец, вебхук, синхронизация) и фильтрами.

## Пометки [v2]
`план изменён после выдачи`, `устарело` (давно у исполнителя без движения: порог 3 суток), `CI красный`, `ждёт вас` (сдано дольше суток).
