# Решения и вопросы владельцу (портал)

## Принято (по обсуждению с владельцем)
- Портал размещается на VPS владельца по адресу `rikagro.ru/createportal` (развёртывание только по отдельной команде).
- Доска в виде схемы GTD (колонки) с переключением на вид по шагам; входящие идеи; подсказки у каждой кнопки и справка.
- При создании проекта выдаются промпты директору: организация репозитория и разработка полного GDD, плюс скелет репозитория.
- Протокол для ИИ: при каждой новой функции директор добавляет этапы и промпты в план проекта.
- Сначала полный GDD портала, затем задания исполнителям.
- **Управление со смартфона** (владелец): портал строится мобильным первым как PWA (установка на экран); отдельный APK не нужен сейчас, возможен позже как оболочка TWA (см. 11_MOBILE_PWA).
- Вид доски: «Дорожки» в стиле liquid glass (выбор владельца).
- **Вебхуки GitHub нужны** (владелец, 2026-11-16): портал сам видит PR и результат CI и отмечает слияние; решение о приёмке остаётся за владельцем.
- **Уведомления нужны**; каналы MAX и/или Telegram через общий интерфейс с адаптерами (см. 05_INTEGRATIONS). Владелец самозанятый, поэтому может подключиться к платформе MAX для партнёров (верификация и модерация бота).

## Вопросы с рекомендацией директора (решить до реализации v2)
| Вопрос | Рекомендация |
|---|---|
| Какой канал первым | MAX, если профиль самозанятого уже есть (работает из России, без зависимости от блокировок); Telegram как второй канал или первый, если нужно быстро (бот создаётся за минуту). Реализуем оба через адаптеры |
| Приёмка «в один клик» или по чек-листу | По чек-листу с возможностью принять вручную и пометкой в журнале |
| Автоматически принимать при слиянии PR | Нет: решение о приёмке остаётся у владельца |
| Несколько пользователей (v3) | Не в первом выпуске; сначала один владелец |
| Хранить ли отчёты и тексты промптов в базе | Да, для истории (только текст, без секретов) |
| Подключать ли ИИ в портале (составлять тексты сообщений) | Не сейчас: портал без ключей ИИ, меньше рисков |
| Доступ с других устройств | Да, через HTTPS и вход по паролю; двухфакторный вход (TOTP) по желанию в v2 |
| Где хранить резервные копии | На втором диске VPS и еженедельная копия на устройство владельца (скачивание из интерфейса) |
