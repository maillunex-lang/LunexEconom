# 01. Вход, роли, безопасность

## Вход [v1]
Один владелец. Логин и пароль; пароль задаётся только на сервере командой `python -m portal.manage set-password <логин>` (скрытый ввод, не короче 14 символов, в чат не передаётся). Хеш scrypt (n=2^14, r=8, p=1, соль 16 байт). Неверные логин и пароль неразличимы; при неизвестном логине время проверки выравнивается.
**Лимиты:** 8 неудачных попыток за 15 минут на IP, затем ответ 429; второй слой в nginx (`limit_req` 10 запросов в минуту на `/api/login`).
**Сессия:** случайный токен 32 байта, в базе хранится только SHA-256; срок 12 часов; cookie `portal_session`: HttpOnly, Secure, SameSite=Strict, Path=/createportal. Смена пароля сбрасывает все сессии.
**CSRF:** отдельный токен на сессию, обязателен в заголовке `X-CSRF-Token` для всех POST (кроме выхода).
**Заголовки:** CSP с nonce на скрипт (`default-src 'none'`), `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `Cache-Control: no-store`.
**Размер запроса** до 1 МБ, JSON только объектом, все поля проверяются.

## v2
- Кнопки «Сменить пароль» и «Завершить все сеансы» в настройках (вход подтверждается текущим паролем).
- Журнал аудита в интерфейсе (вход, смена статуса, импорт плана, синхронизация), последние 200 записей, без секретов.
- Блокировка входа после 20 неудач за час с уведомлением владельцу.
- Двухфакторный вход (TOTP) как необязательная функция.

## v3: роли
| Роль | Права |
|---|---|
| Владелец | всё, включая настройки, пользователей, удаление проектов |
| Редактор | менять статусы, идеи, загружать планы в назначенных проектах |
| Наблюдатель | только чтение |
Права по проектам (список проектов у пользователя). Приглашение по одноразовой ссылке, пароль задаёт сам приглашённый на странице приглашения (не владелец).

## Секреты
Токен GitHub (только чтение) и токены уведомлений лежат в файлах на сервере с правами 0600 вне репозитория и базы; в интерфейсе показывается только «подключён/нет». Ни пароли, ни токены не пишутся в журналы и ответы API.

## Угрозы и меры
| Угроза | Мера |
|---|---|
| Подбор пароля | scrypt, лимиты IP, nginx limit_req, 14+ символов |
| Подделка запросов (CSRF) | токен сессии, SameSite=Strict |
| Внедрение скриптов (XSS) | вывод только через `textContent`, CSP с nonce |
| Кража сессии | HttpOnly, Secure, срок 12 часов, сброс при смене пароля |
| Утечка данных между проектами | выборки всегда с `project_slug`, тесты |
| Подмена плана | план проверяется валидатором перед сохранением |
| Отказ в обслуживании | лимит размера, лимит идей, один процесс за nginx |
