# 06. Отчёты исполнителей, приёмка, метрики

## Отчёт исполнителя [v2]
В панели задачи поле «Отчёт»: вставка текста или ссылки на PR. Портал разбирает ссылку (`github.com/.../pull/N`), показывает PR, ветку, SHA, результаты CI (`server`, `client smoke`, `website`), число файлов и список изменённых файлов с пометкой «вне зоны линии» (сверка с `lanes.<л>.zone`). Макет: `mockups/task_review.svg`.

## Чек-листы
**Самопроверка исполнителя** (из пакета и линии, шаблон):
- линия сервера: полный набор серверных тестов на изолированной БД, флаги выключены, деньги через учёт, зона файлов, раздел «Допущения»;
- линия клиента: все клиентские проверки локально, строки только в файле строк, нет сырых ключей, ничего не обрезается на 16:9 и 20:9, новый тест подключён в CI.
**Приёмка директора** (отмечается в портале):
1. пробное слияние с актуальным `main` без конфликтов;
2. изменены только файлы зоны линии;
3. полные тесты у директора прошли;
4. CI на PR зелёный;
5. слито в `main`.
Кнопка «Принято, в архив» активна, когда отмечены все пункты и CI не красный; владелец может принять вручную с пометкой «без чек-листа» (записывается в журнал).

## Автоприёмка [v2]
По умолчанию задача закрывается сама при слиянии PR в основную ветку с зелёным CI (правила и условия: [05](05_INTEGRATIONS.md)). Ручная приёмка по чек-листу остаётся для случаев, когда автоприёмка выключена или CI не настроен; чек-лист при автоприёмке по умолчанию не требуется. В карточке принятой задачи видна отметка «принято автоматически», PR, SHA и результаты CI.

## Замечания и доработка [v2]
«Вернуть исполнителю» открывает поле замечаний; портал собирает промпт доработки (исходное задание + список замечаний) для копирования; задача возвращается в `issued` с пометкой «доработка №N».

## Метрики [v2]
По проекту и по всем проектам: принято задач за неделю, среднее время от выдачи до сдачи и до приёмки, доля возвратов на доработку, число задач, ждущих владельца, число красных CI. Скорость показывается столбиками по неделям (макет `mockups/overview.svg`). Метрики информационные, не оценивают исполнителей и не блокируют работу.

## Архив [v1]
Принятые задачи с датами и (v2) PR, SHA, отчётом и чек-листом остаются навсегда; возврат из архива возможен. Поиск по архиву [v3].
