# LunexEconom 0.2.3: инкрементальные изменения мира

Реализовано в отдельной ветке: серверный SQLite-журнал событий с монотонным seq, версия каждого чанка 12×12, таблица текущих объектов; GET /events?after=N и GET /chunk?cx=X&cy=Y через HTTPS. Публичные методы только чтение; изменение мира выполняется внутренней функцией world_events.apply(), без открытого игрокам API строительства. События building_created, building_removed, road_changed. Многоклеточный объект обновляет все затронутые чанки.

Клиент Godot опрашивает /events каждые 3 секунды, обновляет только затронутые визуальные чанки, при разрыве версии запрашивает snapshot. В оперативной памяти хранятся server_cells и активные CanvasItem-чанки. Пока нет лимита/LRU для server_cells, курсор событий не сохраняется между запусками, нет проверки подлинности события сверх HTTPS и нет авторизации игровых действий. Начальный серверный журнал пуст; реальные строительные события ещё не создаются игровым UI. Следующий этап: защищённая игровая команда, серверная валидация строительства, синхронизация при старте и на переподключении, LRU, тесты на двух клиентах.

Проверки: Python тесты EVENT_TEST_PASS persistence/version/cross_chunk/remove/cursor; nginx -t OK; /api/events и /api/chunk возвращают 200, публичный POST /api/events 404; Godot 4.7.2 headless запускается без SCRIPT ERROR; Android APK 0.2.3 versionCode 5 apksigner verify успешен, опубликована https://rikagro.ru/lunexeconom/versions/Bashkiria-Honey-Oil-0.2.3-world-events.apk. На реальном Android пока не проверена.

ВНИМАНИЕ: встроенный updater в ранее опубликованной 0.2.2 использует неверное сравнение version_code (>5 вместо >4), поэтому обновление из 0.2.2 может не сработать. В 0.2.3 порог также требует исправления перед следующим релизом; пока APK устанавливать с сайта. Не считать обновлятор проверенным.
