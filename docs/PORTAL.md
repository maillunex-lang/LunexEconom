# CreatePortal: портал проектов

Портал помогает владельцу создавать и вести проекты: список проектов, доска задач по этапам с готовыми промптами, самопроверкой, приёмкой и архивом, мастер создания проекта (скелет репозитория и промпт для ИИ-директора) и протокол для ИИ, как добавлять этапы и промпты. Адрес: `rikagro.ru/createportal` (после развёртывания).

- Код: [`portal/`](../portal/) (Python 3.12, SQLite, только стандартная библиотека), тесты `python -m unittest portal.tests.test_portal`.
- Развёртывание на VPS: [`portal/DEPLOY.md`](../portal/DEPLOY.md), выполняется только по команде владельца (Часть C).
- Протокол для ИИ: [`portal/templates/PORTAL_PROTOCOL.md`](../portal/templates/PORTAL_PROTOCOL.md); попадает в каждый новый проект как `docs/PORTAL_PROTOCOL.md`.
- Как проект попадает на портал: в репозитории лежит `docs/work_plan.json` в стандартной схеме; портал читает его по кнопке «Синхронизировать» (нужен токен GitHub только на чтение, который владелец кладёт на сервер сам) или владелец загружает файл вручную.
- Состояния задач хранятся в базе портала: `planned` (в очереди), `issued` (у исполнителя), `submitted` (сдано), `accepted` (принято, в архив). Выдать можно только пакет, чьи зависимости приняты.
- Копия `portal/templates/work_plan.py` обязана совпадать с `tools/work_plan.py` (проверяет тест); при правке инструмента копируют файл: `cp tools/work_plan.py portal/templates/work_plan.py`.
