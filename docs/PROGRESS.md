## Ограничения текущей реализации
- 🟡 API — **временный каркас**, а не полноценный MMO-backend.
- 🟡 `POST /sessions` — **не аутентификация**: тестовые nickname-сессии живут только в памяти.
- 🟡 Godot показывает стартовый экран и проверяет loopback-адрес; Android-устройство не сможет подключиться к VPS через `127.0.0.1`.
- ⬜ PostgreSQL, финансовый реестр, генерация карты, NPC, торговля, multiplayer sync и APK **не реализованы**.
- ⬜ CI не настроен, подписанного Android APK нет.
- ⚠️ При предварительной проверке VPS swap 2 ГБ был почти заполнен; не проводить тяжёлые сборки без повторной проверки памяти.
