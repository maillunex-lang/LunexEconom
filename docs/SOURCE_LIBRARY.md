# LunexEconom V2: библиотека исходников

**Назначение:** исходный проект для поиска и повторного использования решений в новых играх. Это не GDD новой игры.

## Инструкция ИИ
1. Начни с [карты модулей](MODULE_INDEX.md) и [каталога идей](REUSE_CATALOG.md).
2. Найди исходники, тесты, импорты и зависимости интересующей механики.
3. Различай **код**, **эксперимент** и **только GDD**. Наличие описания не доказывает готовность функции.
4. Переноси только нужную часть в отдельный репозиторий и адаптируй её под новый проект.
5. Проверяй тесты, версии Godot/Python, права на ассеты, конфигурацию и безопасность.

## Не переносить автоматически
Ключи и секреты, боевые URL, настройки VPS, данные пользователей, миграции PostgreSQL без анализа, игровые цены и баланс, привязки к Башкортостану, сторонние ассеты без проверки лицензий.

Каталоги `ops/`, `portal/`, `admin_studio/` не обязательны для новой игры. Документы `docs/gdd/`, `docs/WORK_PLAN.md`, `docs/PROGRESS.md` относятся к прежнему продукту.

Не делать массовую очистку и перенос папок без анализа импортов, тестов и сборки. Не менять VPS, рабочую V2, БД и APK ради организации библиотеки.
