# Админ-панель World Studio, ChatGPT13

## Безопасный вход
World Studio слушает только `127.0.0.1:18991`. Открывать через SSH-туннель или закрытую внутреннюю ссылку Termalin. Игровой `/admin/*` слушает только loopback, отвергает proxy headers и требует отдельный длинный bearer-токен. Токен сервера не попадает в браузер.

## Навигация
- **Панель**: ревизия, месяц, количество аккаунтов, онлайн, пик за сутки, динамика активности по 5-минутным интервалам, статус базы, SHA. Если нет источника метрик, показывается «нет метрики».
- **Игроки онлайн**: игрок, последний запрос, версия клиента, город (если клиент передал его), «Показать» открывает карточку существующего раздела без записи данных игрока.
- **Флаги**: переключатели из серверного реестра. Высокий риск требует подтверждения. Показано, вступит ли настройка в силу со следующего месяца.
- **Параметры**: числовые поля с минимумом, максимумом и значением по умолчанию. Применяется только значение с корректным типом и диапазоном.
- **Ревизии**: история автора и комментария, сравнение и новый откат. Откат создаёт новую ревизию и тоже требует подтверждения.
- **Объявления и обслуживание**: режим обслуживания через защищённую запись; сообщения до 200 символов без HTML публикуются существующей системой объявлений.
- **Журнал**: кто, когда, откуда и что изменил в `adm_audit`.

## Клиентский Live Config
Редактор клиентской конфигурации на вкладке «Ревизии» позволяет задать минимальную и рекомендуемую версию APK и заголовок штаба. Изменения проверяются по диапазону, ожидаемой ревизии и требуют подтверждения. Настройки клиента сначала сохраняются на сервере как черновик. Игроки получают только подписанный экземпляр. Публикация через root-оператора описана в [LIVE_CONFIG.md](LIVE_CONFIG.md). Ключ не хранится в браузере и не передаётся через HTTP.

## Безопасность и ограничения
Каждая запись проходит токен и проверку loopback игрового API, контроль диапазона, ревизии и необходимости подтверждения. Все действия журналируются. World Studio не поддерживает редактирование денег или чужих объектов через эти новые разделы. Текущий интерфейс адаптируется под горизонтальный мобильный экран и desktop, сведения на русском.

Снимки экрана должны быть добавлены после полноценной проверки браузерного интерфейса через SSH-туннель и наполнения тестовой базы; не выдавать макеты за фактические скриншоты.
