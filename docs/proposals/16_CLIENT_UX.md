# Предложение 16. Клиентские экраны и навигация

> **Скелет.** Перед реализацией доработать до полной спецификации (формулы по шагам, алгоритмы, проводки, согласование с модулями 07-10). Не утверждено директором.

**Цель:** карта экранов, действия, пустые состояния, ошибки, связь с API, жесты Android, Forest Glass.

Горизонтальная раскладка, стиль Forest Glass.

## Сущности и данные

- Экраны: штаб, карта, предприятия, поставки, розница, финансы, исследования, реклама, биржа, город, настройки.
- Навигация: нижняя панель, свайпы.

## Правила и формулы

Для каждого экрана: что показывает, главные действия, пустые состояния, ошибки.

**Штаб:** сводка баланса, уведомления, быстрые действия.
Пустое: «Нет предприятий — постройте первое».

**Карта:** 2.5D, здания, участки. Жесты: щипок, зум.

**Предприятия:** список, стадия стройки, загрузка.

**Поставки:** связи, статус.

**Розница:** ячейки, рейтинги, продажи.

**Финансы:** баланс, кредиты, отчёты.

**Исследования:** проекты, уровни.

**Реклама:** бренд, кампании.

**Биржа:** стакан, акции.

**Город:** бюджет, мэр, заказы.

**Настройки:** тема, масштаб, звук.

Обучение первых 10 игровых дней: подсказки по цепочке M1.

## Что считается в суточном тике и что в месячном

Клиент отображает данные с сервера. Обновление по событиям.

## Проводки ledger

Клиент не создаёт проводки напрямую.

## API

Связь с API всех модулей 01–15. Поля кратко описаны в соответствующих файлах.

## Что показывает клиент

Все экраны в стиле Forest Glass, адаптивные, с safe area.

## Приёмка

- Навигация без тупиков.
- Пустые состояния понятные.
- Ошибки показывают причину.
- Обучение проходит цепочку M1 за 10 дней.
