# UI_DATA.md

Ссылки и проверяемые данные для UI proposal.

- Токены: `client/theme/tokens_proposed.json`
- Валидатор: `tools/validate_ui_proposal.py`
- Тесты: `tools/tests/test_ui_proposal.py`

Макеты покрывают 1920x1080 и 2400x1080 для ключевых экранов.
