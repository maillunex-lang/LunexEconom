# Предложение 08. Недвижимость и стройка

**Цель:** дать игроку покупать и арендовать землю, строить здания по стадиям, учитывать амортизацию и налог на имущество, связать с каталогом зданий и ростом населения.

Все расчёты по `docs/proposals/INTEGER_MATH.md`. Никаких float.

## Сущности и данные

- Участок (parcel): 6×6 клеток (из 02), зона (центр, жилая, промзона, окраина), владелец (город / компания / игрок), цена земли (целые ₽).
- Здание: тип из `buildings.json` (03), стадия строительства (0–3: фундамент, каркас, отделка, готово), прогресс в игровых днях, уровень износа (0–100).
- Аренда: договор между компаниями на помещение (офис, склад, магазин).
- Индекс цены земли: зависит от зоны и трафика района (промилле).

Данные: `parcels` (уже в 02), `buildings` (enterprise + stage, wear), `leases`, `land_prices`.

## Правила и формулы

Цена земли (целочисленная):
```
land_price = (base_ufa * city_land_index_‰ * zone_mult_‰ * (1000 + 300 * traffic // 100)) // 1_000_000
```
zone_mult_‰: центр 2000, жилая 1200, промзона 800, окраина 500 (balance: draft).

Стадии строительства (срок в днях = build_days из каталога):
- Фундамент: 25 % срока, 30 % стоимости (промилле 250/300).
- Каркас: 35 % срока, 40 % материалов.
- Отделка: 30 % срока, 20 % материалов.
- Ввод: 10 % срока, 10 % материалов.

Стоимость материалов списывается по стадиям с `company` на `system:materials` (целые ₽).

Амортизация: каждый месяц здание теряет wear_rate пунктов (balance: draft, 1 пункт/мес). При износе > 20 производительность падает линейно до 50 % при 100.

Налог на недвижимость: месячный, `tax = (assessed_value * tax_rate_bp) // 10000`.
assessed_value = land_price + (building_cost * (100 - wear)) // 100.
**Ставка:** 50 bp в месяц (0.5 % в год). Обоснование: для пекарни build_cost 400 000 ₽ (из buildings.json), типичная месячная выручка магазина ~200 000 ₽ (из примеров 06), налог ≈ 2 000 ₽ = 1 % выручки. Для более дорогих зданий не превышает 3–5 %.

Аренда: игрок выставляет помещение по цене за месяц (целые ₽). Другая компания платит проводкой. Срок 1–12 месяцев.

Снос: возвращает 200 ‰ остаточной стоимости материалов (balance: draft), участок освобождается.

## Что считается в суточном тике и что в месячном

**Суточный тик** (`projects`):
- Продвижение стадий строительства (если оплачены материалы и есть рабочие).
- Проверка готовности здания к вводу.

**Месячный шаг:**
- Амортизация всех зданий.
- Налог на недвижимость (проводка).
- Платежи по аренде.
- Обновление цен земли по трафику.

## Проводки ledger

- Покупка земли: `company: -price, city: +price` или `system:land`.
- Стройка: по стадиям `company: -cost, system:materials: +cost`.
- Налог: `company: -tax, system:treasury: +tax`.
- Аренда: `tenant_company: -rent, landlord_company: +rent`.
- Снос: `system:materials: -refund, company: +refund`.

Все суммы целые, request_id идемпотентны, сумма строк = 0.

## API

- `GET /parcels?city` — участки, цены, владельцы.
- `POST /parcels/{id}/buy` — покупка.
- `POST /parcels/{id}/build` — заказ строительства (тип из каталога).
- `GET /buildings/{id}/stage` — прогресс.
- `POST /buildings/{id}/lease` — выставить в аренду.
- `POST /buildings/{id}/demolish`.

## Что показывает клиент

На карте: цена участка, зона, стадия стройки (прогресс-бар), износ здания. В штабе: список своей недвижимости, налог к уплате, арендные договоры.

## Приёмка

- Нельзя построить завод вне промзоны (из 02).
- Стадии идут строго по порядку, деньги списываются только при начале стадии.
- Налог считается от оценочной стоимости и списывается в месячном шаге.
- Аренда между двумя компаниями одного игрока не создаёт искусственной прибыли (консолидация в 10).
- Снос возвращает часть материалов и освобождает участок.
- Все проводки сходятся.

## Открытые вопросы к директору

1. Нужен ли аукцион на землю в M2? Рекомендация: прямая покупка + опционально позже.
2. Сколько стадий — 3 или 4? Рекомендация: 4.
3. Амортизация влияет на производительность сразу или после порога? Рекомендация: линейно после 20 % износа.
4. Можно ли строить жильё игроку для сдачи жителям? Рекомендация: да, упрощённо.
5. Налог на пустующую землю включать? Рекомендация: да.
6. Возврат материалов при сносе 200 ‰? Рекомендация: да.
7. Ипотека в M2? Рекомендация: позже.
8. Зоны меняет только город/админ? Рекомендация: да.

## Дополнительные детали и примеры

### Таблица зон и множителей (balance: draft)

| Зона | Множитель ‰ | Разрешённые роли | Трафик базовый |
|------|-------------|-----------------|----------------|
| Центр | 2000 | магазин, офис, жильё | высокий |
| Жилая | 1200 | жильё, магазин малый | средний |
| Промзона | 800 | завод, склад, добыча | низкий |
| Окраина | 500 | ферма, добыча, склад | очень низкий |

Пример: участок в центре Уфы, traffic = 80 → land_price = base * 1000 * 2000 * (1000+240) // 1e6 ≈ base * 2.48 (целое).

### Стадии строительства — численный пример

Здание grocery_store: build_days = 1, build_cost = 400 000 ₽ (из каталога).
Для больших: bakery build_days = 1, тоже 400 000.

Для здания с build_days = 60 (условно):
- Фундамент: дни 1–15, списание 120 000.
- Каркас: 16–36, 160 000.
- Отделка: 37–54, 80 000.
- Ввод: 55–60, 40 000.

Если нет денег на стадию — стройка пауза.

### Амортизация

wear_rate = 1 пункт в месяц. После 50 месяцев износ 50, производительность 75 % (линейно от 20).

### Налог — расчёт

assessed_value = 800 000 (земля) + (400 000 * 70) // 100 = 1 080 000.
tax = (1 080 000 * 50) // 10000 = 5 400 ₽ в месяц.

Для пекарни с выручкой 150 000 ₽/мес налог ~3.6 %.

### Аренда и снос

Офис 200 м², аренда 15 000 ₽/мес. Проводка каждый месяц. При просрочке 2 месяца — расторжение.

Снос: возврат 200 ‰ остаточной. Участок снова у города или владельца земли.

### Связь с населением

Жильё игрока даёт housing_quality району. Чем больше качественного жилья — тем выше рост pop в 07.

### Граничные случаи

- Попытка построить магазин в промзоне → отказ.
- Параллельная покупка одного участка → только одна успешна (из 02).
- Снос недостроенного → возврат уже оплаченных материалов частично.
