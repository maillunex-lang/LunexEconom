# Предложение 08. Недвижимость и стройка (готово к постановке)

**Цель:** покупка земли, стройка по четырём стадиям с оплатой при входе в стадию, налог на имущество и пустую землю, износ, аренда, снос.

Все по INTEGER_MATH.md. Никаких float. Счета не в минус.

Утверждено (DECISIONS_APPROVED.md):
- D-10, D-53: 4 стадии, оплата частями при входе в стадию
- D-11: износ линейно после 20 %
- D-13: налог на пустую землю
- D-14: снос возвращает 200 ‰

## Сущности и данные

- Участок (parcel): 6×6, зона, владелец, land_price (целые ₽)
- Здание: тип из buildings.json, stage 0–3, progress_days, wear 0–100
- Аренда: договор между компаниями

Цена земли (из world.md):
```
land_price = (15000 * land_index_bp * zone_bp) // 100000000
```
Пример центр Уфы: 15000 * 10000 * 16000 // 100000000 = 24000 ₽.

## Стройка по четырём стадиям (D-10, D-53)

Стадии и доли стоимости (промилле):
1. Фундамент: 250 ‰ срока, 300 ‰ стоимости
2. Каркас: 350 ‰ срока, 400 ‰ стоимости
3. Отделка: 300 ‰ срока, 200 ‰ стоимости
4. Ввод: 100 ‰ срока, 100 ‰ стоимости

Платёж только при входе в стадию. request_id = enterprise:build:<id>:<stage>.
Если на счёте не хватает денег — стадия не наступает, стройка стоит, деньги не списываются.

**Пример:** bakery build_cost = 400000 ₽, build_days = 1
- Стадия 0: списание 120000 ₽ (300 ‰)
- Стадия 1: 160000 ₽
- Стадия 2: 80000 ₽
- Стадия 3: 40000 ₽

## Налог на имущество и пустую землю (D-13)

assessed_value = land_price + (building_cost * (100 - wear)) // 100
tax = (assessed_value * 20) // 10000   // 20 bp/мес

Для пустой земли building_cost = 0, налог только с земли.

**Пример:** центр Уфы, здание 400000, wear=20
assessed = 24000 + (400000 * 80) // 100 = 344000
tax = (344000 * 20) // 10000 = 688 ₽/мес

## Износ (D-11)

wear += 1 в месяц. При wear > 20 производительность = 1000 - (wear - 20) * 5 ‰ (минимум 500 ‰).

## Аренда и снос (D-14)

Аренда: проводка tenant → landlord каждый месяц. Просрочка 2 месяца — расторжение.

Снос: возврат 200 ‰ остаточной стоимости материалов. Участок освобождается.

## Проводки ledger

- Покупка земли: company -price, city:<id> +price. request_id = land_buy:<parcel>
- Стройка стадии: company -cost, system:materials +cost. request_id = enterprise:build:<id>:<stage>
- Налог: company -tax, system:treasury +tax. request_id = tax_property:<company>:<YYYYMM>
- Снос: system:materials -refund, company +refund

Все идемпотентны, сумма 0, счета >= 0.

## Что считается в тиках

**Суточный (projects):** продвижение стадий, если оплачена.
**Месячный:** амортизация, налог на имущество и пустую землю, аренда.

## API

## Приёмка (8 сценариев)

1. Центр Уфы land_price = 24000
2. Стадии идут по порядку, деньги списываются только при входе
3. Нехватка денег → стадия не наступает
4. Налог 688 ₽ при assessed 344000
5. Пустая земля платит налог только с land_price
6. Снос возвращает 200 ‰
7. Параллельная покупка одного участка — только одна успешна
8. Износ >20 снижает производительность линейно
