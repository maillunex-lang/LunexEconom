# Предложение 08. Недвижимость и стройка

**Цель:** дать игроку покупать и арендовать землю, строить здания по стадиям, учитывать амортизацию и налог на имущество, связать с каталогом зданий и ростом населения.

Все расчёты по `docs/proposals/INTEGER_MATH.md`. Никаких float. Счета не уходят в минус.

## Сущности и данные

- Участок (parcel): 6×6 клеток (из 02), зона (центр, жилая, промзона, окраина), владелец (город / компания / игрок), цена земли (целые ₽).
- Здание: тип из `buildings.json` (03), стадия строительства (0–3: фундамент, каркас, отделка, готово), прогресс в игровых днях, уровень износа (0–100).
- Аренда: договор между компаниями на помещение (офис, склад, магазин).
- Индекс цены земли: зависит от зоны и трафика района (промилле).

Данные: `parcels` (уже в 02), `buildings` (enterprise + stage, wear), `leases`, `land_prices`.

## Правила и формулы

Цена земли (из docs/world.md, целочисленная):
```
land_price = ceil( (15000 * land_index_bp * zone_bp) // 100000000 )
```
Где zone_bp: center 16000, residential 10000, industrial 11500, free 6000. land_index_bp Уфы = 10000.

**Пример:** участок в центре Уфы.
- 15000 * 10000 * 16000 = 2 400 000 000 000
- // 100000000 = 24000
- остаток 0, ceil = 24000 ₽.

Стадии строительства (срок в днях = build_days из каталога):
- Фундамент: 25 % срока, 30 % стоимости (промилле 250/300).
- Каркас: 35 % срока, 40 % материалов.
- Отделка: 30 % срока, 20 % материалов.
- Ввод: 10 % срока, 10 % материалов.

Стоимость материалов списывается по стадиям с `company` на `system:materials` (целые ₽). Если недостаточно средств — стройка на паузе.

Амортизация: каждый месяц здание теряет wear_rate пунктов (balance: draft, 1 пункт/мес). При износе > 20 производительность падает линейно до 50 % при 100.

Налог на недвижимость: месячный, `tax = (assessed_value * property_tax_bp_month) // 10000`.
assessed_value = land_price + (building_cost * (100 - wear)) // 100.
**Ставка:** 20 bp в месяц (0.2 % в месяц = 2.4 % в год). Обоснование: для пекарни/магазина build_cost 400 000 ₽, типичная месячная выручка ~150 000–200 000 ₽, налог не превышает 3 % выручки.

**Пример налога:** assessed_value = 24 000 (земля, центр Уфы, формула выше) + (400 000 * 80) // 100 = 24 000 + 320 000 = 344 000.
tax = (344 000 * 20) // 10000 = 688 ₽ в месяц. Для выручки 150 000 ₽ это около 0,46 %.

Аренда: игрок выставляет помещение по цене за месяц (целые ₽). Другая компания платит проводкой. Срок 1–12 месяцев. При просрочке 2 месяца — расторжение.

Снос: возвращает 200 ‰ остаточной стоимости материалов (balance: draft), участок освобождается.

## Что считается в суточном тике и что в месячном

**Суточный тик** (`projects`):
- Продвижение стадий строительства (если оплачены материалы и есть рабочие).
- Проверка готовности здания к вводу.

**Месячный шаг:**
- Амортизация всех зданий.
- Налог на недвижимость (проводка).
- Платежи по аренде.
- Обновление цен земли по трафику.

## Проводки ledger

- Покупка земли: `company: -price, city:<id>: +price` (или system:treasury вне города). request_id = `land_buy:<parcel>:<request>`.
- Стройка: по стадиям `company: -cost, system:materials: +cost`. request_id = `build_stage:<building>:<stage>`.
- Налог: `company: -tax, system:treasury: +tax`. request_id = `tax_property:<company>:<YYYYMM>`.
- Аренда: `tenant_company: -rent, landlord_company: +rent`. request_id = `lease:<lease_id>:<YYYYMM>`.
- Снос: `system:materials: -refund, company: +refund`.

Все суммы целые, request_id идемпотентны, сумма строк = 0. Счета не уходят в минус.

## API

- `GET /parcels?city` — участки, цены, владельцы.
- `POST /parcels/{id}/buy` — покупка.
- `POST /parcels/{id}/build` — заказ строительства (тип из каталога).
- `GET /buildings/{id}/stage` — прогресс.
- `POST /buildings/{id}/lease` — выставить в аренду.
- `POST /buildings/{id}/demolish`.

## Что показывает клиент

На карте: цена участка, зона, стадия стройки (прогресс-бар), износ здания. В штабе: список своей недвижимости, налог к уплате, арендные договоры.

## Приёмка

1. Участок центр Уфы → land_price = 24000 ₽.
2. Нельзя построить завод вне промзоны (из 02).
3. Стадии идут строго по порядку, деньги списываются только при начале стадии.
4. Налог 20 bp от assessed 1 120 000 = 2240 ₽.
5. Аренда между двумя компаниями одного игрока не создаёт искусственной прибыли (консолидация в 10).
6. Снос возвращает 200 ‰ остаточной и освобождает участок.
7. Все проводки сходятся, счета >= 0.
8. Параллельная покупка одного участка → только одна успешна (из 02).

## Открытые вопросы к директору

1. Нужен ли аукцион на землю в M2? Рекомендация: прямая покупка + опционально позже. Последствие: проще в M2.
2. Сколько стадий — 3 или 4? Рекомендация: 4. Последствие: больше контроля денег.
3. Амортизация влияет на производительность сразу или после порога? Рекомендация: линейно после 20 % износа. Последствие: реалистичнее.
4. Можно ли строить жильё игроку для сдачи жителям? Рекомендация: да, упрощённо. Последствие: связь с 07.
5. Налог на пустующую землю включать? Рекомендация: да. Последствие: стимул застройки.
6. Возврат материалов при сносе 200 ‰? Рекомендация: да. Последствие: баланс.
7. Ипотека в M2? Рекомендация: позже. Последствие: проще финансы.
8. Зоны меняет только город/админ? Рекомендация: да. Последствие: контроль.

## Дополнительные детали и примеры

### Таблица зон и множителей (из world.md)

| Зона | zone_bp | Разрешённые роли | Трафик базовый |
|------|---------|-----------------|----------------|
| Центр | 16000 | магазин, офис, жильё | высокий |
| Жилая | 10000 | жильё, магазин малый | средний |
| Промзона | 11500 | завод, склад, добыча | низкий |
| Окраина | 6000 | ферма, добыча, склад | очень низкий |

### Стадии строительства — численный пример

Здание grocery_store / bakery: build_days = 1, build_cost = 400 000 ₽ (из каталога).
Для здания с build_days = 60 (условно, например refinery):
- Фундамент: дни 1–15, списание 120 000.
- Каркас: 16–36, 160 000.
- Отделка: 37–54, 80 000.
- Ввод: 55–60, 40 000.

Если нет денег на стадию — стройка пауза.

### Амортизация

wear_rate = 1 пункт в месяц. После 50 месяцев износ 50, производительность 75 % (линейно от 20).

### Аренда и снос

Офис 200 м², аренда 15 000 ₽/мес. Проводка каждый месяц. При просрочке 2 месяца — расторжение.

Снос: возврат 200 ‰ остаточной. Участок снова у города или владельца земли.

### Связь с населением

Жильё игрока даёт housing_quality району. Чем больше качественного жилья — тем выше рост pop в 07.

### Граничные случаи

- Попытка построить магазин в промзоне → отказ.
- Параллельная покупка одного участка → только одна успешна (из 02).
- Снос недостроенного → возврат уже оплаченных материалов частично.
