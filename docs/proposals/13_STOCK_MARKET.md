# Предложение 13. Фондовый рынок

**Цель:** ввести IPO, торги акциями, дивиденды, поглощения, рыночную капитализацию.

Все по INTEGER_MATH.md. Счета не уходят в минус.

## Сущности и данные

- Акция: компания, количество, владельцы.
- Заявка: купля/продажа, цена, объём.
- Дивиденд: выплата на акцию.

Данные: `shares`, `orders`, `dividends`, `market_cap`.

## Правила и формулы

IPO: выпуск N акций по цене P. Капитал = N * P.

Торги: стакан заявок, сопоставление по цене и времени.

Дивиденд = (profit * payout_‰) // shares_count.

Защита от манипуляций: лимит ордеров в день, минимальный объём.

**Пример:** IPO 1000 акций по 1000 ₽. Капитал 1 000 000 ₽.

## Что считается в суточном тике и что в месячном

**Суточный:** сопоставление заявок.

**Месячный:** выплата дивидендов, отчёт по рынку.

## Проводки ledger

- IPO: `investors: -money, company: +money`.
- Сделка: `buyer: -price, seller: +price`.
- Дивиденд: `company: -total, shareholders: +share`.

## API

- `GET /market/orders` — стакан.
- `POST /market/order` — заявка.
- `POST /market/ipo` — выпуск.
- `GET /companies/{id}/cap` — капитализация.

## Что показывает клиент

Стакан, график цены, свои акции, дивиденды.

## Приёмка

- Заявки сопоставляются по правилам.
- Дивиденды выплачиваются только из прибыли.
- Нагрузка на сервер ограничена лимитами.
