# Цифры пакетов контента (balance: draft)

Обоснование целых лимитов из `tools/sim/data/content_proposed/limits.json`. Это потолки, не целевой размер первого выпуска. Байты везде целые. 1 МиБ здесь = 1048576 байт.

Проверка не качает сеть и не хранит ключей. Хорошие примеры обязаны проходить схему и логику. Плохой пример обязан не проходить.

## Что уже зашито в клиенте и не поднимается

| Потолок | Число | Откуда |
|---|---:|---|
| Манифест | 65536 | `client/update/manifest_verifier.gd`, `LIMIT` |
| Один пакет в клиенте | 104857600 | `valid_payload(..., 100 * 1024 * 1024)` |
| Пакетов в старом клиенте | 100 | `valid_content`, массив `packs` |
| Кеш | 524288000 | `client/content/content_manager.gd`, `MAX_CACHE_BYTES` |
| Один исходный файл до сборки | 62914560 | `tools/build_packs.py`, `MAX_ASSET` |

Предложение может быть только строже. Выше этих чисел схема не ставит ничего: старый клиент такой пакет молча отвергнет.

## Потолки предложения

| Ключ | Число | Почему |
|---|---:|---|
| `max_manifest_bytes` | 65536 | Равен клиенту. Запас на 8 пакетов с короткими подписями SHA-256 есть, раздувать некуда. |
| `max_packs` | 8 | Шесть видов и два запасных слота. Старый клиент разрешает 100, нам столько не нужно. Меньше поверхность для циклов и для лишнего скачивания. |
| `max_release_bytes` | 67108864 | 64 МиБ на весь выпуск. Ниже кеша в 8 раз, чтобы несколько старых выпусков ещё помещались, пока чистильщик их не снял. |
| `cellular_budget_bytes` | 20971520 | 20 МиБ за один заход по сотовой. Полный выпуск по сотовой не качается специально: 20 < 64. Сначала обязательная тема, если она влезает. |
| `cache_bytes` | 524288000 | Уже зашито. Менять клиент ради другой цифры не за чем. |
| `client_pack_ceiling_bytes` | 104857600 | Потолок старого клиента. Ни один вид его не превышает. |
| `min_release` | 1 | Нулевой номер занят ответом «встроенное». |
| `max_release` | 2000000000 | Влезает в знаковый 32-бит и в `maximum` схемы. Выше не обещаем. |

Сумма потолков видов = 8 + 8 + 12 + 32 + 16 + 16 = 92 МиБ. Это больше 64 МиБ выпуска нарочно. Нельзя одновременно упереться в потолок карты и в потолок звуков. Выпуск выбирает, что везти.

| Вид | Потолок, байт | Оценка |
|---|---:|---|
| `icons_goods` | 8388608 | около 200 значков WebP по 40 КиБ. Каталог сейчас меньше, запас на цепочки. |
| `icons_buildings` | 8388608 | тот же порядок, зданий меньше, картинка может быть крупнее значка товара. |
| `ui_theme` | 12582912 | панели, шрифт, состояния кнопок. Обязательный пакет, поэтому он один обязан влезать в сотовые 20 МиБ. 12 < 20. |
| `map_tiles` | 33554432 | самый тяжёлый вид. Половина бюджета выпуска, не больше. |
| `season` | 16777216 | замена части темы и карты, не вторая полная копия всего. |
| `sounds` | 16777216 | несколько коротких ogg, не музыкальный архив. |

Хранение на VPS: 8 выпусков × 67108864 = 536870912 байт, если каждый упёрся в потолок. Это решение про диск, не про кеш телефона.

## Примеры

Хеши — заглушки. Длина каждого ровно 64 шестнадцатеричных знака, чтобы схема SHA-256 была честной. Файлов `.pck` за этими хешами нет.

| Файл | Выпуск | Пакеты | Сумма, байт | Ожидание |
|---|---:|---|---:|---|
| `icons_goods.json` | 2 | иконки товаров, background | 2097152 | годный |
| `ui_theme.json` | 2 | тема, required | 3145728 | годный |
| `season_winter.json` | 3 | тема 3145728 + карта 8388608 + `season_winter` 4194304 | 15728640 | годный |
| `incompatible.json` | 9 | сезон с URL `evil.example` и цикл с темой | 2000 | отказ |

Зимний пример, 15728640 байт, меньше и 64 МиБ выпуска, и 20 МиБ сотовой квоты. Его можно скачать целиком даже по сотовой. Это пример, не обещание боевого размера: боевая карта может быть больше квоты и тогда уедет на Wi-Fi.

Плохой пример специально проходит схему JSON (виды, размеры, имена валидны) и падает на двух правилах логики: цикл `season_bad → ui_theme → season_bad` и URL не с `https://rikagro.ru/lunexeconom/v2/packs/`. Так проверка не сводится к одной только схеме.

`min_version_code` в хороших примерах = 1001. Альфа считает `versionCode = 1000 + N` (`docs/release.md`), первый выпуск клиента — 1001. Пакет не ставится на более старый APK. В плохом примере код 1, чтобы было видно: схема пускает любой код от 1, а пол отката контента — это другое поле, `content_min_release`, его в манифесте нет.

Версия пакета во всех примерах равна строке `release`. Смешивать `icons_goods` из выпуска 2 и зиму из выпуска 3 нельзя: это два разных подписанных файла.

## Что сознательно не число

- Нет целевого числа игроков на новой графике. Считаются запросы процесса, не люди.
- Нет отдельного лимита «сколько раз откатить за день». Хватает пола и аудита.
- Нет дробных мегабайт в настройках. В интерфейсе можно показать целые МиБ делением на 1048576, в данных остаётся байт.
