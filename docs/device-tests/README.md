# Проверка APK на реальном Android

До публикации GitHub Release создать отдельный отчёт `docs/device-tests/<version>.md` по **конкретному APK**, указав:

```text
Result: PASS
Device: <модель, версия Android>
APK SHA256: <64 шестнадцатеричных символа>
```

Добавить реальные наблюдения: установка, запуск, горизонтальная ориентация, safe area, масштаб интерфейса, сетевые ошибки, возврат из фона, повторный запуск. При проблемах указывать `Result: FAIL`.

**Не отмечать PASS без установки и запуска на реальном устройстве.** Релизный workflow дополнительно сравнит SHA256 с исходным APK, скачанным из успешной сборки GitHub Actions. Workflow требует подтверждения окружения `android-release` в GitHub Settings, если настроены required reviewers.

Пока релизы основаны на **debug-подписи** и должны иметь статус prerelease. Для стабильного релиза нужен отдельный постоянный signing key в GitHub Secrets и выпуск с release-подписью.
